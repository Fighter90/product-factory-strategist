Аргументы: $ARGUMENTS (язык прогона: `ru`, `en` или `all`; пусто — спроси руководителя).

Запусти ночной/ручной прогон качества агента «Стратег Фабрики продуктов» (PRO-64):

1. Языки: `ru` → antispam-ru, budget-app-ru, price-increase-ru; `en` → те же задачи с суффиксом -en;
   `all` → оба языка (6 прогонов).
2. Для каждой задачи выполни из корня репозитория:
   `scripts/e2e_opencode.sh <lang> qa/tasks/<задача>-<lang>.md`
   Скрипт сам: свежий клон во временный каталог → `opencode run --auto --format json` с режимом
   автопрогона ([PRO-54]) → разбор лога (`tools/pfs/e2e.py`) → отчёт
   `qa/E2E-<дата>-<задача>-<lang>.md`.
   Прогон идёт 20–40 минут — не прерывай его и не запускай несколько параллельно.
3. Отчёт по каждой задаче покажи руководителю одной строкой: имя отчёта, вердикт (✅/❌),
   шаги, ошибки инструментов, остановки (`pfs ask`), токены, время.
4. Если ворота не пройдены (❌) — не правь код и реестры клона сам; выпиши из отчёта
   2–3 главные ошибки и спроси руководителя, заводить ли дефект.
5. Итог: сводную таблицу шести прогонов (или запрошенного языка) добавь в конец
   `docs/demo/comparison.md` в раздел «Прогоны PRO-64», если её там ещё нет.
