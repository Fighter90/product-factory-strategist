# Реестр навыков (PRO-65)

Навык — повторяемая процедура, которую среда подключает по формулировке задачи. В `.claude/skills`
загружаются только навыки, привязанные к **шагу процесса** или к **сценарию агента**.

Итого: **100** навыков = базовые 13 (шаги процесса) + 27 product-skills (процедуры методов)
+ 3 интеграции + 57 из личной библиотеки (сценарии).

Колонка «Кто вызывает»: `среда` — авто-подключение по `description` задачи; `навык шага` —
подключается навыком соответствующего шага; `руководитель` — явный запрос («используй skill X»);
`субагент` — отчёт субагента. При конфликте методология `knowledge/` (карты) приоритетнее процедуры навыка.

обновить этот реестр и счётчики (`python3 scripts/update_skill_counts.py --write`).

## Как вызывать — три способа

1. **Автоматически** — среда читает `description` навыка и подключает его по формулировке задачи
   («сделай premortem», «оцени лендинг по веб-гайдлайнам»).
2. **Явно** — «используй skill `<имя>`: `<задача>`» (например, «используй skill `deck`: собери деку»).
3. **В процессе агента** — навык шага подключает нужные: `pfs step` печатает обязательные карты, а skills
   включаются на шагах (options → `options` + red-team; decision → `decision-support` + `premortem`).
   Примеры команд: `pfs questions options`, `pfs export --deck`.

## MCP для отчётов/презентаций (состояние)

- **Linear** — подключён (ключ в .env): задачи ведутся по программе.

- **Feynman** (feynman.is) — CLI research-агент для глубокого ресёрча: skill `deep-research`.
