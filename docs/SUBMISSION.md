# Стратег Фабрики продуктов — описание работы

> Документ для жюри. Конвертируется в PDF: `pandoc docs/SUBMISSION.md -o submission.pdf` (или «Печать → PDF» из GitHub).
> Скриншоты для PDF: вывод команд из раздела 7 и файлы `projects/demo-antispam/outputs/*`.

## 1. Что это и как запустить

Репозиторий-агент для руководителя цифрового продукта: превращает размытый запрос и разнородные материалы в проверяемую
картину ситуации, ≥3 содержательно разных варианта (вкл. «оставить как есть» и «закрыть») и согласованные продуктовую и
коммуникационную стратегии с планом проверки; после решения — сопровождение (основания, обязательства, пересмотр).

Запуск: Python 3.9+ без пакетов → `python3 -m tools.pfs doctor` → открыть папку в Claude Code и написать задачу.
Подробно — [README](../README.md).

## 2. Архитектура

См. [ARCHITECTURE.md](ARCHITECTURE.md). Кратко:

- **Процесс:** route → intake ⏸ → sources → research → situation → options (+red team) → choice ⏸ → strategy →
  validation → review → decision ⏸ → monitoring. ⏸ — решает человек; остальное агент ведёт сам и отмечает шаги в state.json.
- **Инструменты:** CLI `pfs` (stdlib Python): состояние и продолжение, реестр источников (загрузка сайтов/PDF/DOCX/XLSX/CSV,
  дедупликация, детектор внедрённых инструкций, разрешённые домены, защита от SSRF), реестр утверждений с правилами,
  quality gate, анализ влияния, решения, стоимость по транскриптам, поиск по базе знаний, профиль данных и когорты,
  маршрутизация сценариев и моделей. Те же функции — по MCP (`.mcp.json`).
- **Контекст и знания:** инструкции (AGENTS.md, skills, agents) / методические знания (knowledge/, 51 карта) / настройки
  (config/) / материалы проекта (projects/*/sources) / состояние (state.json, *.jsonl) / результаты (outputs/) — раздельно.
  Агент не грузит базу целиком: `pfs route` даёт список карт, `pfs kb search` — разделы карт (BM25).
- **Хуки:** SessionStart (контекст проекта при новом чате), PreToolUse/WebFetch (разрешённые домены),
  PostToolUse (журнал, детектор инструкций в веб-ответах, автопроверка документа), Stop (стоимость).

## Ограничения

- Агент — это инструкции для LLM-среды: качество зависит от модели; детерминированы только инструменты (`pfs`).
- Веб-поиск — средствами среды; часть сайтов блокирует автоматическую загрузку (тогда `--text-file` + URL).
- Синтетические интервью не доказывают спрос; реальные интервью проводит человек, в репозиторий — без ПДн.
- Мультимодальность — средствами модели среды; инструменты хранят описание, а не распознают изображения/аудио сами.
- Стоимость автоматически считается только для Claude Code (по транскриптам); для других сред — `pfs log --usd`.
- Проверка `numbers_need_tags` — эвристика (регулярные выражения): возможны ложные предупреждения; ошибки — только по правилам.
- Роутер сценариев — по ключевым словам; при низкой уверенности нужен уточняющий вопрос или субагент `router`.
- Субагенты Claude Code, созданные в ходе сессии, подхватываются после её перезапуска.
