# Ключевые решения (ADR)

| # | Решение | Почему | Цена / альтернатива |
|---|---|---|---|
| 1 | Агент = папка с инструкциями + CLI, а не приложение | Требование задачи; работает в любой IDE-агентной среде; легко проверять и развивать | Нет собственного UI — прогресс показывается в чате и файлах |
| 2 | Реестр утверждений (claims.jsonl) с типами и правилами в коде | Проверяемость нельзя доверить «дисциплине модели»: правило «факт ⇒ источник» исполняется инструментом | Агенту нужно больше вызовов CLI; окупается меньшим числом ошибок и правок человеком |
| 3 | Теги [C###] в документах + pfs check | Автоматически видно числа без источника, ссылки на отозванное, неполные разделы | Регулярные выражения иногда дают ложные предупреждения (не ошибки) |
| 4 | Выводы агента — тип inference с derived_from | Память между сеансами не превращает прошлый ответ в факт; impact видит цепочки | — |
| 5 | Модели под задачи в config/models.json, а не в промптах | Одна точка настройки; дешёвые модели на массовые простые задачи; эскалация при ошибке; другие провайдеры профилем | Нужно поддерживать соответствие субагентов (pfs models sync) |
| 6 | Детерминированный роутер сценариев + LLM-роутер только при низкой уверенности | Бесплатно и воспроизводимо в 80% случаев | Ключевые слова требуют пополнения; исправление через --override фиксируется в журнале |
| 7 | 3 точки участия человека (бриф, выбор, решение) | Человек решает существенное, но не отвечает на лишние вопросы | В автономном прогоне агент ждёт ответа |
| 8 | Синтетические респонденты как отдельный origin | Можно быстро искать гипотезы, но инструмент не даст выдать их за факт | Нужны реальные интервью для доказательств |
| 9 | Только stdlib Python | «Запуск без скрытых настроек»; работает на любом ПК | Упрощённые PDF/XLSX-парсеры; для сложных PDF — pdftotext/pypdf (необязательно) |
| 10 | Методические карты — дистилляция своими словами, без слайдов | Авторское право, компактность, токены | Детали лекций остаются в исходниках у владельца |
| 11 | Безопасность на уровне инструментов | Источник — данные; SSRF-защита; запрет секретных путей; запрещённые домены через хук | Некоторые легитимные адреса (внутренние сайты) потребуют ручного добавления текста |
