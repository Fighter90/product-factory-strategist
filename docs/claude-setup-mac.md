# Сетап Claude на macOS: скрипт + промпт

Комплект для развёртывания на чужих аккаунтах Claude. Проверен на чистой macOS (Apple Silicon, без Homebrew, Node и Python).

---

## Что человек делает руками и почему только это

Два действия автоматизировать нельзя — это ограничения платформы, а не недоработка промпта:

| Действие | Почему нельзя поручить Claude |
|---|---|
| Запустить скрипт установки | Пока Desktop Commander не установлен, у Claude нет shell на Mac. Терминал выдаётся управлению компьютером только в режиме «click»: ввод с клавиатуры запрещён. Папка `~/Library/Application Support/Claude/` защищена. Приложение Claude не отдаётся под управление. |
| Нажать кнопку установки плагина | Скилы аккаунта хранятся на диске как кэш синхронизации с сервером — запись туда перезатирается приложением. Установка возможна только через интерфейс. |

Всё остальное — проверка, настройка, Python, распаковка и валидация пакета скилов, отчёт — делает Claude сам.

**Порядок для получателя:** вставить скрипт в Терминал → перезапустить Claude → вставить промпт в новую задачу Cowork → нажать кнопку установки плагина.

---

## Что раздавать

1. Этот файл.
2. `product-skills.plugin` — 27 продуктовых скилов. Без него последний шаг не сработает.

## Часть 1. Скрипт установки

Получатель открывает Терминал (⌘Space → «Терминал») и вставляет всё одним куском. Работает без прав администратора. Занимает 3–5 минут.

```bash
#!/bin/bash
set -euo pipefail

echo "==> 1/5 Desktop Commander и Node.js"
curl -fsSL https://raw.githubusercontent.com/wonderwhy-er/DesktopCommanderMCP/refs/heads/main/install.sh | bash

echo "==> 2/5 Менеджер окружений uv"
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"

echo "==> 3/5 Python 3.12 и библиотеки для аналитики"
uv python install 3.12
uv venv --python 3.12 "$HOME/.venvs/main"
uv pip install --python "$HOME/.venvs/main/bin/python" pandas numpy matplotlib openpyxl

echo "==> 4/5 Пути для неинтерактивных оболочек"
touch "$HOME/.zshenv"
grep -q '.local/bin' "$HOME/.zshenv" || \
  printf '%s\n' '# Claude setup: ~/.local/bin для неинтерактивных оболочек' \
                'export PATH="$HOME/.local/bin:$PATH"' >> "$HOME/.zshenv"
ln -sf "$HOME/.venvs/main/bin/python" "$HOME/.local/bin/python3"
ln -sf "$HOME/.venvs/main/bin/python" "$HOME/.local/bin/python"

echo "==> 5/5 Настройка Desktop Commander"
CFG="$HOME/.claude-server-commander/config.json"
mkdir -p "$(dirname "$CFG")"
[ -s "$CFG" ] || echo '{}' > "$CFG"
PATCH="$(mktemp)"
cat > "$PATCH" <<'JS'
const fs = require('fs');
const p = process.argv[2];
let c = {};
try { c = JSON.parse(fs.readFileSync(p, 'utf8') || '{}'); } catch (e) { c = {}; }
c.defaultShell = '/bin/zsh';
c.fileWriteLineLimit = 500;
c.telemetryEnabled = false;
if (!('allowedDirectories' in c)) c.allowedDirectories = [process.env.HOME];
fs.writeFileSync(p, JSON.stringify(c, null, 2));
console.log('config обновлён:', p);
JS
node "$PATCH" "$CFG"
rm -f "$PATCH"

echo
echo "================================================"
echo "Готово."
echo "Python:  $HOME/.venvs/main/bin/python"
echo "Доступ Desktop Commander ограничен домашней папкой."
echo
echo "Дальше: закрыть Claude через Cmd+Q и открыть заново."
echo "================================================"
```

### Что делает скрипт

| Шаг | Результат |
|---|---|
| 1 | Desktop Commander + Node.js, запись в `claude_desktop_config.json` (прежние настройки не затрагиваются) |
| 2–3 | `uv`, Python 3.12 в `~/.venvs/main`, библиотеки pandas, numpy, matplotlib, openpyxl |
| 4 | `~/.zshenv` с путём `~/.local/bin`, симлинки `python` и `python3` |
| 5 | Конфиг Desktop Commander: shell `/bin/zsh`, лимит записи 500 строк, телеметрия выключена, доступ ограничен домашней папкой |

### Если нужен полный доступ ко всей файловой системе

Заменить в скрипте строку

```js
if (!('allowedDirectories' in c)) c.allowedDirectories = [process.env.HOME];
```

на

```js
c.allowedDirectories = [];
```

Пустой массив означает доступ ко всему диску. По умолчанию оставлена домашняя папка — для раздачи это разумнее.

## Часть 2. Промпт

После перезапуска Claude получатель создаёт новую задачу в Cowork и вставляет текст ниже первым сообщением.

````markdown
# Проверь и доведи сетап Claude на этом Mac

Сессия связана с моим компьютером (macOS). Установочный скрипт уже отработал. Выполни всё ниже сам, без уточняющих вопросов. Останавливайся только там, где это прямо указано.

## Чего не пытайся делать

Эти пути закрыты платформой. Не трать на них попытки и не ищи обходов:

- Терминал под управлением компьютером работает в режиме «click» — ввод с клавиатуры запрещён.
- Папка `~/Library/Application Support/Claude/` защищена, доступ к ней не выдаётся.
- Приложение Claude не отдаётся под управление компьютером.
- `device_bash` работает в изолированной Linux-песочнице, а не в macOS. Для моих файлов используй только инструменты `desktop-commander__*`.

Если инструментов `desktop-commander__*` нет — скажи об этом прямо, попроси меня перезапустить Claude через Cmd+Q и останови работу.

## Шаг 1. Проверка установленного

Собери одной таблицей:

- версия Desktop Commander,
- версия Node.js и путь,
- версия Python из `~/.venvs/main/bin/python`,
- версии pandas, numpy, matplotlib, openpyxl (проверь импортом, не по списку файлов),
- содержимое `~/.claude-server-commander/config.json`: `defaultShell`, `fileWriteLineLimit`, `telemetryEnabled`, `allowedDirectories`,
- блок `desktop-commander` в `~/Library/Application Support/Claude/claude_desktop_config.json`.

## Шаг 2. Починка конфига

Если значения разошлись с целевыми, приведи их к ним через `set_config_value`:

| Ключ | Значение |
|---|---|
| `defaultShell` | `/bin/zsh` |
| `fileWriteLineLimit` | `500` |
| `telemetryEnabled` | `false` |

`allowedDirectories` не трогай — что выставил скрипт, то и оставь.

## Шаг 3. Пакет продуктовых скилов

1. Найди на компьютере архив с именем, содержащим `product-skills` (проверь Desktop, Downloads, Documents). Распакуй его.
2. Проверь пакет: ровно 27 папок вида `<имя>/SKILL.md`; в каждом файле есть поля `name` и `description`; `name` совпадает с именем папки; состав `.plugin` совпадает со списком папок. При расхождении остановись и покажи его.
3. Положи копию `product-skills.plugin` в корень Рабочего стола, рядом — копию с расширением `.zip` (некоторые окна выбора файлов не показывают `.plugin`).
4. Отдай мне файл `product-skills.plugin` в чат: в превью есть кнопка установки. Запасной путь назови текстом: Customize → Plugins → загрузка файла.

После установки проверь, что видны все 27 скилов вида `product-skills:<имя>`, и назови точку входа — `product-navigator`.

Не предлагай дублировать те же скилы загрузкой в аккаунт claude.ai: описания 27 скилов занимают около 8,4 тыс. токенов в каждой сессии, дубль удваивает расход.

## Шаг 4. Правила работы

Зафиксируй и применяй дальше:

- Скилы применяй сам, без вопроса «подключить ли». На пограничной задаче одной строкой называй выбранный скил.
- Действия с последствиями — отправка сообщений, публикация, покупки, удаление файлов, изменение настроек — только с моего подтверждения.
- Файлы правь на месте командой или скриптом, который сам читает файл. Не перенабирай содержимое из вывода инструментов: вывод обрезается, так теряются данные.
- Python вызывай по абсолютному пути `~/.venvs/main/bin/python`. Системный `python3` перехватывается заглушкой Apple, перезаписать её без `sudo` нельзя, а `sudo` заблокирован в Desktop Commander.
- Результаты клади рядом с исходниками, не в служебные папки.
- Если что-то заблокировано платформой — скажи прямо и назови причину.

## Шаг 5. Отчёт

Одной таблицей: что стоит, какие версии, что настроено. Отдельной строкой — что не удалось и почему.
````

## Известные особенности

**Окно «Установить инструменты командной строки разработчика».** Может появиться, если что-то вызовет системный `/usr/bin/python3` — на чистой macOS это пустая заглушка. Окно можно закрыть кнопкой «Отмена»: Python ставится отдельно, в `~/.venvs/main`.

**Уже установленный Homebrew или свой Python.** Скрипт отработает, но создаст ещё одно независимое окружение. Таким получателям лучше заранее сказать, чтобы они пропустили шаги 2–3.

**Ограничение по времени в device-shell.** Команда через мост к компьютеру обрывается примерно на 60 секундах. Установка Python занимает дольше — поэтому она вынесена в скрипт, который человек запускает в Терминале напрямую, без этого ограничения.

**Корпоративные ноутбуки.** Скрипт скачивает и выполняет код из интернета (`raw.githubusercontent.com`, `astral.sh`). На рабочей машине с политиками безопасности это стоит согласовать заранее, а содержимое обоих установщиков — открыть по ссылкам и просмотреть.
