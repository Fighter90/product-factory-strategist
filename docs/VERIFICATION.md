## Что остаётся сделать человеку

1. Записать видео по сценарию [VIDEO_SCRIPT.md](VIDEO_SCRIPT.md) (до 10 минут).
2. Собрать PDF описания из [SUBMISSION.md](SUBMISSION.md) и добавить скриншоты.
3. Когда МегаФон опубликует бриф — прогнать его как новый проект: `python3 -m tools.pfs new "<название>" "<запрос>"`.

## Известные ограничения (не дефекты)

- Агент — инструкции для LLM-среды: детерминированы только инструменты `pfs`, качество рассуждений зависит от модели.
- Часть сайтов блокирует автоматическую загрузку — текст добавляется вручную с указанием ссылки.
- Синтетические интервью дают только гипотезы, а не доказательство спроса.
- Стоимость считается автоматически только в Claude Code (по транскриптам); в других средах — `pfs log --usd`.
