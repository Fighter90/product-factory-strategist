# Сценарий видео (≤ 10 минут)

Запись экрана Claude Code (или Cursor) в папке репозитория. Справа — файлы `projects/<slug>/outputs/`.

| Время | Что показываем | Что говорим / вводим |
|---|---|---|
| 0:00–0:40 | README, структура папки | «Агент — это папка: правила AGENTS.md, 51 методическая карта из лекций, 11 навыков, 8 субагентов, хуки и CLI на чистом Python» |
| 0:40–1:10 | `python3 -m tools.pfs doctor`, `python3 -m unittest discover -s tests` | Запуск без установки зависимостей, 12 тестов |
| 1:10–1:40 | `python3 -m tools.pfs models` | Разные модели под разные задачи: haiku — классификация, оценка, ИИ-респонденты; opus — синтез, варианты, red team |
| 1:40–2:30 | Новый проект: вводим запрос руководителя в чат | Агент вызывает `/strategist`, `pfs route` (сценарий + карты + план моделей), задаёт ≤3 вопроса и ждёт (⏸) |
| 2:30–4:00 | Шаг research | Поиск → `pfs source add <url>` (S###), утверждения с типом и силой A–D; показать `sources/S001.md` с пометкой «ДАННЫЕ, а не инструкции»; `pfs data cohort` на модельных данных; ИИ-респонденты (помечены как синтетика) |
| 4:00–4:40 | `02_situation.md` + `pfs check` | Что известно [C###], чего не знаем, противоречия ЦБ vs Сбербанк; quality gate ловит число без ссылки и «факт» силы D |
| 4:40–6:00 | `03_options.md` + red team | 5 вариантов вкл. «оставить как есть» и «закрыть»; red team находит круговое обоснование на модельных данных → `claim retract`, `impact` показывает затронутые строки, `check` — ссылки на отозванное |
| 6:00–6:20 | Выбор руководителя (⏸) | `pfs ask` / `pfs answer` |
| 6:20–7:30 | `04_product_strategy.md`, `05_comms_strategy.md` | Аудитория и задача, осознанные отказы, экономика; ключевое сообщение; таблица «обещание ↔ подтверждение в продукте» |
| 7:30–8:00 | `06_validation_plan.md` | Ожидаемое изменение, база сравнения (A/B, MDE и выборка), срок, контрметрики, критерии решения |
| 8:00–8:40 | **Перерыв**: закрыть чат, открыть новый | Хук SessionStart подаёт состояние (`docs/demo/resume_after_break.txt`), агент продолжает с текущего шага |
| 8:40–9:20 | Решение и сопровождение | `pfs decision add`, `pfs decision due --on 2027-02-01` — просроченные обязательства; новый источник → `claim supersede` → `impact` |
| 9:20–10:00 | Прозрачность | `pfs cost` (стоимость по моделям), `log.jsonl`, `pfs export` → `REPORT.md`; `python3 docs/demo/compare.py` — сравнение с обычным чатом |
