# Wardley Mapping: стратегия по карте, а не по интуиции

## Когда применять
Нужно понять, где у продукта/рынка компоненты «ещё не существуют», а где — «стали электричеством»; решить, что строить самому, что покупать, что отдать провайдеру; найти моменты для атаки.

## Суть
- **Карта**: ось X — эволюция компонента (Genesis → Custom-built → Product (+rental) → Commodity/utility), ось Y — видимость для пользователя (цепочка потребностей от вершины вниз). Компоненты — существительные; связи — «нужен для».
- **Эволюция = движение по X со временем независимо от воли игрока** (стандартизация, конкуренция). Позиция определяет игру: Genesis — исследовать, Custom — строить под себя/дифференциатор, Product — покупать/арендовать, Commodity — потреблять как электричество.
- **Климатические сигналы**: конкуренция снижает цены, стандартизация неизбежна, «успех вчерашнего дня» и др. — по карте видно, что вот-вот эволюционирует (окно возможностей/рисков).
- **Игры**: атаковать эволюционирующие компоненты конкурентов (их дифференциатор стал commodity), строить выше по цепочке, отдавать не-дифференциаторы провайдеру.
- Практика: карта рисуется с командой за 1–2 часа на доске; проверяется рынком, не «истина».

## Как делать
1. Определить пользователя и его потребность (вершина цепочки).
2. Выписать компоненты вниз по «нужен для»; расставить по эволюции (где рынок: сколько поставщиков, стандарты?).
3. Пометить движение (что эволюционирует сейчас) и враждебные/дружественные позиции.
4. Стратегия: build для Custom-дифференциаторов, buy/rent для Product, следить за Genesis-окнами.

## Подводные камни
- Карта раз и навсегда — это процесс, обновлять.
- Оценка эволюции «по желанию», а не по рынку (число поставщиков, стандартизация).
- Фичи на карте вместо компонентов-существительных.
