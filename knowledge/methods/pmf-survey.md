# PMF-опрос: измерить product/market fit одним вопросом

## Когда применять
Продукт живёт несколько месяцев, есть активные пользователи — нужно понять, есть ли PMF и на каком сегменте, прежде чем вкладываться в рост.

## Суть
- Ключевой вопрос активным пользователям: **«Как вы расстроитесь, если продукт больше не будет доступен?»** — «очень разочарован(а)» / «немного» / «не очень» / «не помог».
- Ориентир Шона Эллиса: **≥40% «очень разочарован(а)»** — предвестник PMF. Меньше 40% — продукт ещё не обязан масштабироваться: сначала продукт/сегмент.
- **Главное — не среднее, а сегментация**: найти, КТО эти 40% (по роли, сценарию, частоте, каналу прихода) и усилить продукт/маркетинг именно для них (метод Superhuman: строим профиль «высокого скора», сужаем позиционирование, работаем только с этим сегментом до следующего замера).
- Дополнить открытые вопросы: «Какой тип людей наиболее выигрывает?», «Какую главную пользу вы получаете?» — формулировки для позиционирования берутся из ответов, не выдумываются.
- Опрос не заменяет удержание: PMF-скор без повторного использования — ложный сигнал.

## Как делать
1. Отобрать активных (например, ≥N сессий за месяц); опрос в продукте, не по холодной базе.
2. Собрать ≥40–80 ответов сегментообразующего объёма; посчитать долю «очень разочарован(а)» и разрезы.
3. Выделить сегмент с максимальным скором → интервью с ними → формулировка ценности их словами.
4. Решение: скорм ≥40% + удержание → рост; ниже — дискавери (дерево возможностей) и/или смена сегмента.

## Подводные камни
- Опрашивать всех подряд (включая «попробовавших раз») — скор занижается без диагноза.
- Вера в средний процент без разрезов — главный сигнал (сегмент) теряется.
- Замер один раз и навсегда: PMF — движение, замер повторяется после значимых изменений.
