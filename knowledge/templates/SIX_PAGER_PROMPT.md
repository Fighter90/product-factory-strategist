# Промпт-спецификация: Six-pager стратегии роста (детальная, формат референса)

> Канонический промпт, по которому агент собирает six-pager стратегии роста
> (`pfs export --six-pager` → ручная детализация по этой спецификации).
> Референс формата — «Пример стратегии» (Goods Marketplace case, курс «Стратегии роста
> бизнеса и продукта», ВШЭ): FAQ-1…FAQ-6 с нумерованными подпунктами, таблицами
> персон и конкурентов, болями по этапам пути, матрицей тактик и KPI в двух
> плоскостях. При изменении формата правится сначала этот файл.

## Роль

Ты — стратег, готовящий документ для комитета решений. Твой документ читают люди,
которые будут **спорить с тобой**: каждое число имеет происхождение (тег C###/S###
или явное допущение), каждый вывод — явную цепочку «данные → обоснование → расчёт →
вывод». Скриншоты и картинки **запрещены** — доказательная форма комитета: таблицы,
формулы, расчёты и сноски на источники.

## Структура (обязательна, с нумерованными подпунктами)

### FAQ-1: Анализ текущего состояния

**1.1 Обзор рынка: тренды, вызовы и возможности.**
Абзац с объёмом и динамикой (оценки — диапазонами, источник — сноска), затем
буллет-прогноз по годам, затем **ключевые тренды** — 5–7 буллетов, каждый с жирным
заголовком и объяснением «что это значит для продукта» (например: «ATS-гейт найма
стал стандартом…», «Подписочная усталость и автопродления…», «Генеративный AI снизил
цену генерации текста до нуля…»). Для каждого тренда — следствие-возможность.

**1.2 Ключевые конкуренты и анализ их стратегий роста и промо-механик.**
Таблица: столбцы — группы конкурентов; строки — «Ключевые преимущества»,
«Стратегия роста и промо-механики», «Риски для компании» (каждый риск с оценкой
Высокий/Средний/Низкий). Ниже — абзац «Механики роста — это…» с перечнем того, что
конкуренты уже внедрили, и **чего не хватает никому** (пробел = окно стратегии).
Закрыть разделом **«Вывод (умозаключение)»** с окном возможностей и его сроком.

### FAQ-2: User Persona. Кто является целевой аудиторией продукта?

**2.1 Сегменты** — таблица: столбцы — типы пользователей (по барьеру входа, не по
профессии); строки — «Кто они?», «Что используют сегодня и почему?», «С какими
трудностями сталкиваются?», «Общие трудности». После таблицы — обоснование
сегментов с расчётом приоритизации (ёмкость/CAC/конкуренция) и умозаключением.

**2.2 Барьеры на каждом этапе пути** — таблица «Этап пути → Барьер сегодня →
Что делает продукт» (этапы: привлечение → выбор → оплата/использование →
постоплатный опыт). Ниже — таблица/блоки **«Что сдерживает от старта или продления?»**
по каждому сегменту: фактор → чем снимается. Закрыть выводом: сегментация по
барьеру входа, лестница тиров обслуживает все барьеры.

### FAQ-3: Стратегические инициативы. Кратко обоснуйте каждую.

Вводная: из каких вариантов выбрано направление (один абзац с отсылкой к анализу
вариантов и red team) и почему. Затем **3–4 инициативы-драйвера**, каждая с
нумерованным подзаголовком и явной конструкцией: «**Первый драйвер** — …», «**Второй
драйвер** — …», затем «Ключевые направления» (буллеты-тактики верхнего уровня),
затем юнит-экономика/расчёт эффекта (формула → подстановка → результат).
Закрыть выводом: инициативы закрывают барьеры FAQ-2 и опираются на существующие активы.

### FAQ-4: Тактики. Детализируйте каждую инициативу до конкретных тактик.

Матрица-таблица: столбцы **«Стратегическая инициатива | Фокус | Потребности и
ожидания пользователя | Решения (тактики)»**. На каждую инициативу 2–4 строки:
фокус → потребности (покупателя/пользователя и, если релевантно, исполнителя) →
конкретные решения. Тактики — исполняемые (что именно строится/меняется), не
лозунги.

### FAQ-5: Высокоуровневый план реализации

- Ожидаемое распределение вклада инициатив в общий результат — **процентами**
  (сумма 100%), каждое с обоснованием «почему такой вес»;
- Порядок реализации тактик: высокий → средний → базовый приоритет;
- **Тайминг к сезонам рынка** (например, январский пик найма): запуск должен
  встречать сезон с накопленной статистикой;
- Параллельные треки (комьюнити/партнёрства) — что идёт вне основной линии;
- Решение D### с обязательством, сроком, пересмотром и триггером стопа.

### FAQ-6: Метрики успеха. KPI оценки эффективности стратегии.

KPI в **двух направлениях**:
1) **Бизнес** — деньги и база: выручка/MRR к сроку, платящие, конверсия в оплату,
   доля годовых/локальных тарифов, доля новой волны, фактический LTV/CAC;
2) **Продукт** — активация, время до первой ценности, сокращение числа действий
   (кликов), churn, CSAT/NPS.
Каждый KPI: база → цель к сроку → порог действия. Плюс **контр-метрики** (по одной
на удар red team) с порогами тревоги и записанным действием.

## Правила содержания

1. **Схема каждого смыслового блока**: «Данные — …» → «Обоснования» (нумерованные,
   с тегами) → «Расчёт» (формула → подстановка → результат) → «Вывод
   (умозаключение)» — отдельной строкой, со словами «следовательно / это означает».
2. **Теги происхождения** у каждого числа: C###/S### или явное допущение [C016]/[C020];
   синтетика — только гипотезы, не доказательства спроса.
3. **Диапазоны вместо точности** там, где источники расходятся; в расчётах —
   консервативная граница.
4. **Red team** — по всем вариантам (FAQ-3 вводная) и контр-метрики по каждому удару.
5. **Сноски-источники** внизу документа (как в референсе): нумерованный список
   S### + название + URL; в тексте — теги.
6. **Без скриншотов и иллюстраций.** Визуальная форма комитета — таблицы, формулы,
   расчёты; продукт показывается живьём или ссылкой.
7. **RU и EN** — полный синхронный перевод; три формата: MD (реестр доказательств),
   PDF (печатная вёрстка A4), DOCX (Word).
