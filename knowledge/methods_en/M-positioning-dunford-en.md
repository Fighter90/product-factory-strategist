# April Dunford Positioning (EN summary)

**When:** launching a product or entering a new segment; a "good product nobody understands"; conversion sags because the category is unclear; competitors explain themselves more simply.

**Core:** positioning is **context** that makes your product's value obvious — not a tagline or a comparison table. Six components, in order: (1) competitive alternatives (including status quo and spreadsheets) → (2) unique attributes → (3) value those attributes enable (feature ≠ value) → (4) target segments that care most → (5) market category as the frame of reference → (6) trends that amplify the value. Three category options: head-to-head in an existing category, a new category (expensive, requires educating the market), or a hybrid frame ("like X for Y"). A trend works only if it is directly tied to your attributes' value. Output is a positioning document that rewrites the pitch, landing page, and messaging.

**How:** honest list of alternatives → attributes none of them have → translate into value themes (3–5) → pick best-fit segments → choose the category frame (+ optional trend) → write the document, rewrite the pitch/landing, validate on first customer touches or via A/B.

**Pitfalls:** positioning for everyone positions for no one; listing features instead of value; a new category demands a market-education budget; fitting yourself into a hype category without unique attributes is guaranteed failure.
