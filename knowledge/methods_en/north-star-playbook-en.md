# North Star Playbook (EN summary)

**When:** teams and stakeholders pull in different metric directions; you need one agreed metric of delivered customer value plus its drivers.

**Core:** NSM measures delivered value, not activity (revenue is an outcome, not a North Star). Six criteria: reflects value, measures result, not vanity, drives business, simple for the team, actionable. Then an input-metric tree: 3–5 inputs (breadth, frequency, depth, quality), each with an owner and a counter-metric; teams move inputs — NSM follows.

**How:** one-sentence value statement → candidate NSMs scored by the criteria → fix definition & window → build the input tree → wire into roadmap → quarterly review.

**Pitfalls:** revenue as NSM; five "north stars"; an input tree without owners.
