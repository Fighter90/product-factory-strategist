# Lean Startup (EN summary)

**When:** high uncertainty — new product, segment or channel; you need the cheapest loop that converts doubt into validated facts.

**Core:** Build–Measure–Learn starts from WHAT to learn (hypothesis), then the minimal experiment, measured against a criterion fixed in advance. MVP = an experiment, not a mini-product: it tests the single riskiest assumption (types: concierge, wizard-of-oz, single-feature, pre-sale). Innovation accounting: baseline → movement toward the goal → decision. Pivot is a norm — only after validated learning. Hypothesis classes: value, growth, monetization.

**How:** "We believe [segment] suffers [problem] and will [action] if [solution]" → minimal experiment + success criterion BEFORE results → run → record validated learning → persevere / pivot / next riskiest assumption.

**Pitfalls:** no pre-registered success criterion; vanity metrics; quarter-long cycles.
