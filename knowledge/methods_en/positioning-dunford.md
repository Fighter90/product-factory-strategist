# Dunford positioning: context, not a slogan

## When to apply
You are launching a product or entering a new segment; the product is "good, but nobody understands what it's for and how it differs"; funnel conversion sags because the category is unclear; competitors explain themselves more simply and clearly.

## Core idea
- Positioning is **context** that makes the product's value obvious to specific buyers; it is not a slogan, not a comparison table and not "our playful tone of voice".
- **6 components**: (1) **competitive alternatives** — what customers would replace the product with if it didn't exist (including "do nothing", manual processes and Excel); (2) **unique attributes** — what only you have; (3) **value** — the results the attributes give the customer (a feature ≠ value); (4) **target segments** — those who need this value the most (best-fit customers); (5) **market category** — the frame through which the buyer "reads" your product; (6) **trends** — external forces that amplify the value.
- The chain is mandatory in the order 1→6: alternatives define the attributes, the attributes define the value, the value defines the segments, the segments and value define the category, the category defines which trends are relevant.
- **3 category options**: head-to-head (fighting inside an existing category), a new category (creating your own — expensive and slow, the market has to be educated), hybrid (moving the product into a different frame: "like X for Y").
- A trend is only an amplifier, directly tied to the value of the attributes; a trend for a trend's sake adds noise and distrust.
- The output is a **positioning document**: alternatives, attributes, value, segments, category, trends; the pitch, the landing page and the messaging are rewritten from it.

## How to do it
1. Write out an honest list of competitive alternatives, including the status quo and "the customer does it by hand".
2. Find the attributes that none of the alternatives have (including the inconspicuous ones: data, integrations, the payment model, support).
3. Translate the attributes into values: "what the customer gains / stops suffering from"; group them into 3–5 value themes.
4. Select the segments for which these values are an acute pain: who already pays the alternatives the most, and whom you can actually reach.
5. Choose the category frame in which the value is most obvious, and, if justified, add an amplifying trend.
6. Fix the positioning in a document, rewrite the pitch/landing page, and validate the wording on the first customer touches (qualitatively or via A/B).

## Pitfalls
- Positioning "for everyone" is positioning for no one: the segment is chosen deliberately, and everyone else is deliberately ignored.
- Features instead of value: a list of attributes without "why this matters to the customer" doesn't position anything.
- A new category requires budget and time to educate the market; without a strong distribution resource, a hybrid frame is usually the more profitable move.
- Squeezing into a hype category without your own unique attributes is a guaranteed failure: the category is derived from your strengths, not the other way around.
