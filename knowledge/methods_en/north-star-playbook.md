# North Star Playbook: one value metric and its drivers

## When to apply
The team and stakeholders are moving different metrics (revenue vs loyalty vs reach), and priorities conflict — you need one agreed value metric for the customer and a tree of its drivers.

## Essence
- **North Star Metric (NSM)** — the metric where customer value and the long-term business result converge; it measures delivered value, not activity (inputs). Pattern examples: Airbnb — nights booked; Spotify — time with music; Amplitude — "weekly learnings of weekly actives".
- **6 requirements for an NSM** (per the playbook): it reflects value, measures an outcome, is not vanity, moves the business, is simple for the team, and leads to action.
- **The input-metric tree**: the NSM breaks down into 3–5 inputs (space: breadth, frequency, depth, quality); the inputs break into sub-metrics agreed between teams. Teams move the inputs — the NSM moves as a consequence.
- **Not an NSM**: revenue (a result, not value), sign-ups, time in the app without context.
- **Paired with counter-metrics**: each input has a control metric, so growth does not break quality.

## How to do it
1. State the value in one sentence ("who gets what, and what it changes in their lives").
2. Iterate NSM candidates against the 6 criteria; pick one and fix its definition and window.
3. Build the input tree: 3–5 inputs, each with an owner and a control metric.
4. Build it into the roadmap: initiatives → inputs → NSM; revise the tree quarterly.

## Pitfalls
- NSM = revenue — customer value disappears.
- 5+ "north stars" — priorities conflict again.
- An input tree without owners — decoration.
