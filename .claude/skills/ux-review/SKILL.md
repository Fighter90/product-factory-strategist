# UX-разбор

Карты: `M-ux-heuristics`, `M-cjm`, `M-usability-testing`, `M-dogfooding`. Субагент: `ux-analyst`.

1. Зарегистрируй материал: скриншот/видео → `pfs source add <файл> --origin own|public`; страница → URL.
2. Опиши путь: шаги пользователя, экран каждого шага, что на нём видно (заголовок, ключевые элементы, CTA, цена,
   условия). Описание сохрани как источник: `pfs source add --text-file ux_<экран>.md --title "Описание: …"`.
3. Находки по эвристикам (видимость статуса, соответствие ожиданиям, контроль, единообразие, предотвращение ошибок,
   узнавание, гибкость, минимализм, помощь при ошибках, справка): для каждой — экран, элемент, что видно,
   какая эвристика, серьёзность 0–4, последствие для метрики. Что не видно в материале — только гипотеза.
4. Сопоставь с конкурентами (тот же сценарий, тот же шаг) — таблица.
5. Находки → утверждения (`fact`: «на экране X нет цены до шага 3» [S###]; `hypothesis`: «это снижает конверсию»).
