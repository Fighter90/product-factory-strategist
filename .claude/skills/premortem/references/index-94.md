# Premortem — библиотека каркасов по категориям (94 каркаса)

> Библиотека готовых premortem-каркасов. Каждый каркас: сценарий провала в прошедшем
> времени → ранние сигналы-чекбоксы → скрытые допущения → контрмеры → пересобранный план.
> Использование в агенте: найди ближайшую категорию, возьми СТРУКТУРУ каркаса и заполни
> данными проекта (метрики — через C###, сигналы — наблюдаемые события).

## Как пользоваться
1. Выбери категорию и ближайший каркас.
2. Перенеси структуру на цель проекта: сценарий в прошедшем времени, топ-3 точки отказа.
3. Ранние сигналы преврати в чекбоксы, привязанные к метрикам 06_validation_plan.
4. Скрытые допущения — со статусами подтверждено/неизвестно/опровергнуто (опровергнутое → пересмотр решения).
5. Контрмеры → обязательства D### (что|кто|когда).

## Для продуктовых целей (агентский контекст)
Для проектов агента каркасы категорий «Карьера и доход», «IT и технологии» и «Долгосрочные
цели» ложатся на: запуск продукта, рост метрики, монетизация, выход на новый сегмент —
структура та же: сценарий провала → сигналы → допущения → контрмеры → план.
