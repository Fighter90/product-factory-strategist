# Анализ трендов и сценарное планирование

## 🔗 Правило цитирования источников (ОБЯЗАТЕЛЬНО)

**При поиске информации в интернете: ВСЕ числа, факты и утверждения должны иметь гиперссылки прямо на источник.**

Правильно: «Рынок ИИ вырос на [40%](https://example.com/report) в 2024 году» или «По данным [McKinsey](https://mckinsey.com/ai), инвестиции в AI удвоились».

Неправильно: Сноски внизу, «согласно источникам» без ссылок, факты без подтверждения.

## Block 1: Терминология и виды трендов

### Сигнал vs Хайп vs Тренд vs Инсайт vs Мегатренд

| Понятие | Определение | Пример |
|---------|------------|---------|
| **Сигнал** | Ранний индикатор, аномалия, «зерно» тренда | Водородный самолёт ZeroAvia поднялся в воздух |
| **Хайп** | Всплеск интереса без гарантии устойчивости | NFT, Метаверс (пик интереса уже прошёл) |
| **Тренд** | Устойчивая последовательность с чётким направлением | Удалённая работа выросла с 5% до 30% рынка |
| **Инсайт** | Влияние/изменение для вашего продукта | Для B2B-CRM → инсайт: нужна интеграция с удалённым софтом |
| **Мегатренд/Драйвер** | Фундаментальная сила, движущая множество трендов | Климатизация, цифровизация, демография |
| **Образ будущего** | Представление о будущем при развитии трендов | Колонизация Марса, искусственный интеллект везде |

### Виды трендов по PESTLE
- **Political** — регуляция, политика, законы
- **Economic** — инвестиции, курсы, инфляция
- **Social** — культура, ценности, демография
- **Technological** — IT, инновации, автоматизация
- **Legal** — нормативная база, стандарты
- **Environmental** — климат, ресурсы, ESG

## Block 2: Зачем прогнозировать?

### Шахматная метафора
«Скорость одинаковая, дальнозоркость разная». Конкурент движется с той же скоростью, но видит доску на 5 ходов вперёд — у него преимущество.

### 3 горизонта стратегии (McKinsey)
1. **Run (1–3 года)** — текущая прибыль, эффективность
2. **Change (2–5 лет)** — будущая прибыль, адаптация
3. **Disrupt (3–10 лет)** — прорывной рост, новые рынки

---

## Block 3: Когда НЕ прогнозировать

Не тратьте ресурсы на прогноз, если:
- ✗ Результат не влияет на решение
- ✗ Цена ошибки < цена промедления
- ✗ Скорость изменений > скорость планирования
- ✗ Пространство решений слишком сложное (>3 переменных)

## Block 4: 6 методологий прогнозирования

### 1. Horizon Scanning
**Поиск сигналов для предугадывания трендов**
- Скан источников: научные статьи, стартапы, патенты, новости
- Пример: [WHO Global Health Security Index 2022](https://www.ghsindex.org/)

### 2. Delphi-метод
**Анонимные раунды опросов экспертов**
- 2–3 раунда → эксперты видят результаты других → консенсус
- Пример: [ENISA Cybersecurity Outlook 2030](https://www.enisa.europa.eu/)

### 3. Scenario Planning
**Несколько образов будущего, адаптация стратегии** (Пьер Вак, [Shell](https://www.shell.com/))
- Не «что будет», а «что может быть»
- 2–4 сценария, у каждого своя логика

### 4. Diffusion Models
**Скорость внедрения (Bass, Logistic, Gompertz)**
- S-кривая: медленный старт → ускорение → плато
- Пример: Электромобили в [Скандинавии уже 80% продаж](https://www.statista.com/outlook/mmo/electric-vehicles)

### 5. Backcasting
**От желаемого будущего к настоящему**
- «Если в 2030 году мы лидер в категории, что надо делать сейчас?»
- Amazon: [future press release](https://www.aboutamazon.com/news/company-news/amazon-shareholder-letter)

### 6. Prediction Markets / Crowd Forecasting
**Торговля исходами, коллективная мудрость**
- Пример: [Metaculus.com](https://www.metaculus.com/), PredictIt

### Бонус: System Dynamics
**Задержки и циклы обратной связи** (Jay Forrester, MIT)
- Пример: [IEA World Energy Outlook](https://www.iea.org/reports/world-energy-outlook-2023)

## Block 5: Сценарный анализ — простой метод (10 шагов)

### Пошаговый процесс

1. **Определить детали** — конкретный тренд, рынок, горизонт
2. **Измеримая величина** — выразить в метриках (%, млн, индекс)
3. **Baseline** — текущее состояние, траектория на стабильность
4. **Сценарий ускорения** — благоприятные условия
5. **Сценарий отката/остановки** — неблагоприятные условия
6. **Драйверы/триггеры** — что двигает каждый сценарий
7. **Сигналы** — как заранее понять, какой сценарий идёт
8. **Адаптация продукта** — что менять в продукте/стратегии
9. **Разделить действия**:
   - а) Действия при любом исходе (no-regret moves)
   - б) Ставки на исход (option bets)
10. **Готовность продукта** — оценить текущую позицию

## Block 6: Сценарный анализ — матрица 2×2

### Компактный метод для 2 трендов

1. **Выбрать 2 тренда** — наиболее влияющие, но наименее связанные
2. **Оси** — крайние значения (High/Low для каждого)
3. **Матрица** — 4 квадранта с образами будущего
4. **Далее** — аналогично простому методу (шаги 6–10)

```
             Тренд B (High)
                 |
   Сценарий 1  | Сценарий 2
   ─────────────┼─────────────
   Сценарий 3  | Сценарий 4
                 |
           Тренд A (Low)
```

## Block 7: Критерии качества сценариев

| Критерий | Значение |
|----------|----------|
| **Plausibility** | Сценарий правдоподобен, основан на фактах |
| **Internal Consistency** | Логика не конфликтует внутри сценария |
| **Distinctiveness** | Сценарии действительно отличаются друг от друга |
| **Decision Relevance** | Сценарий влияет на реальные решения |
| **Traceability** | Разбирается до драйверов и сигналов |
| **Testability** | Есть наблюдаемые, проверяемые сигналы |

## Block 8: Ограничения и когнитивные ошибки

- **Confirmation Bias** — ищем подтверждение своим гипотезам
- **Overconfidence** — переоцениваем точность прогноза
- **Survivorship Bias** — видим только успехи, игнорируем неудачи
- **Authority Bias** — слепо верим гуру в предметной области
- **Излишне длинный горизонт** — за 10 лет слишком много неизвестного
- **Black Swans** — непредсказуемые события с большим влиянием

**Ключевое**: Будущее — это не закон природы. Это образ в голове, экстраполяция настоящего. Измеряйте и обновляйте.

---

## Block 9: Как прогнозировать правильно

✓ Регулярно и небольшими порциями (ежемесячно, не ежегодно)
✓ Приоритизировать только важные тренды (не все сразу)
✓ Прокачивать «чувствилище» — ретроспективы улучшают качество
✓ Документировать гипотезы и проверять их через 3–6 месяцев
