# Интервью и модельные респонденты

Карты: `M-in-depth-interviews`, `M-interview-analysis`, `M-jtbd`, `M-synthetic-respondents`, `M-audience-research`.

## Гайд (реальные интервью)
1. Цель интервью ← вопросы плана исследования. Критерии рекрута (поведение, а не демография).
2. Гайд по шаблону `knowledge/templates/interview_guide.md`: разогрев → последний реальный случай → путь и
   альтернативы → барьеры → ценность/цена → завершение. Вопросы о прошлом опыте, без подсказок и «а вы бы…?».
3. Согласие собеседника и обезличивание: в репозиторий — только расшифровки без ФИО, телефонов, e-mail
   (замени на R1, R2…). Регистрация: `pfs source add interviews/real/R1.md --origin interview`.

## Анализ
4. Кодируй фрагменты (барьер, мотив, альтернатива, триггер, цитата). Группируй по паттернам. Для каждого паттерна:
   у скольких из N он встретился, контрпримеры.
5. Утверждения из интервью: `--kind fact` только для «N из M респондентов сказали/сделали X»; обобщение на рынок —
   `hypothesis` (качественные данные не доказывают распространённость).

## ИИ-респонденты (поиск гипотез, пилот гайда)
6. Опиши 3–5 контрастных персон (контекст, задача, альтернатива, ограничения) в `interviews/synthetic/personas.md`.
7. Для каждой — субагент `synthetic-respondent` с гайдом. Сохраняй ответы в `interviews/synthetic/<persona>.md`
   с шапкой «СИНТЕТИЧЕСКИЙ ОТВЕТ». Регистрация: `pfs source add … --origin synthetic`.
8. Из ответов — только `--kind hypothesis` + план проверки на реальных людях. В документах помечай «(синт.)».
