# Анализ данных

Карты: `M-product-metrics`, `M-quant-methods`, `M-unit-economics`, `M-market-sizing`, `M-traction-model`.
Субагент: `data-analyst`.

1. Сначала профиль: `pfs data profile <file> --save profile_<имя>` — типы, пропуски, дубли, единицы, пропущенные
   периоды. Каждое предупреждение — либо исправить (и записать как), либо назвать ограничением.
2. Проверь определения: что именно считается (активный пользователь, отток, выручка — с НДС?), период, гранулярность.
   Неясное определение → `pfs question`.
3. Удержание: `pfs data cohort <file> --user <col> --date <col> --save cohorts`. Для других расчётов пиши короткий
   скрипт в `projects/<slug>/analysis/*.py` (только stdlib/pandas, если установлен), сохраняй вывод рядом;
   в документах ссылайся на файл расчёта.
4. Рынок и экономика — по картам M-market-sizing / M-unit-economics: входы с источниками, формула, результат,
   проверка на здравый смысл, диапазон (пессимист/база/оптимист).
5. Результаты → `pfs claim add … --kind fact --source S###` (если на данных) или `forecast`/`inference`.
