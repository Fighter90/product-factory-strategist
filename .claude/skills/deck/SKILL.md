# Deck: из six-pager в презентацию

## Источник и структура
Слайды строятся из `outputs/SIX_PAGER.md` (1 слайд = раздел) + титул + Excel-приложения:
1. Титул: проект, запрос, дата, получатель.
2. FAQ-1..FAQ-6 — по слайду; числа переносятся с тегами [C###]/[S###].
3. Слайд «Экономика»: скрин/выжимка из `attachments/unit_economics.xlsx` (лист Юнит-экономика).
4. Финал: решение, которое просим принять, + обязательства.

## Инструменты (по убыванию предпочтения)
1. **officecli** (`~/.local/bin/officecli`) — AI-friendly CLI для .pptx: `officecli help` → схема.
   Паттерн: создать файл → `officecli add <deck.pptx> /slides` (слайд) → `officecli set` (текст/свойства),
   `officecli get/query` — проверка; `officecli watch <file>` — live-превью в браузере для руководителя.
2. **HTML-дека** (fallback, без зависимостей): `outputs/presentations/deck.html` — простые слайды CSS
   (16:9, один тезис на слайд), печать в PDF через браузер.
3. **Визуалы**: фоны/иллюстрации слайдов — Higgsfield `generate_image` (расходует кредиты — спросить),
   стиль согласовать с site/ (тёмный, акцент #4fd1c5→#8b7bff).
4. **Web-версия деки/лендинг**: Lovable MCP (OAuth: `/mcp` → lovable → Authenticate; create_project
   расходует кредиты Lovable) — бриф: docs/lovable-brief.md.

## Процедура
1. Убедись, что SIX_PAGER.md собран (`pfs export --six-pager`) и `pfs check` без ошибок.
2. Спроси формат: PPTX (officecli) или HTML.
3. Собери деку по структуре выше; числа не пересказывай — копируй с тегами.
4. Покажи руководителю: путь, план слайдов, что редактировать; предложи watch-превью.

## Ограничения
- officecli — внешний CLI из окружения пользователя; если его нет — HTML-fallback.
- Диаграммы из Excel не встраиваются автоматически: добавь ссылку на книгу и значение-кэш.
