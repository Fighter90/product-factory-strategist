# Продуктовые ставки и портфель инициатив

## Обязательные правила работы с внешними данными

**КРИТИЧЕСКИ ВАЖНО:** Любая информация из внешних источников должна быть верифицирована и снабжена ссылками.

### Формат цитирования

**Ссылки ставятся ПРЯМО НА цифрах и утверждениях — как гиперссылки в тексте, а НЕ списком внизу.**

Каждое число, факт или заявление из внешнего источника = гиперссылка на этом числе/факте.

Используй веб-поиск для: бенчмарков конверсий, кейсов проверки гипотез, примеров портфелей крупных компаний.

## Блок 1. Продуктовые фокусы

### Место фокусов в архитектуре решений

**Стратегический:** Цель → Стримы → Драйверы
**Тактический:** **Фокусы** → **Ставки**
**Операционный:** Инициативы → Эксперименты

### Фокус ≠ гипотеза ≠ инициатива

- **Фокус** — направление концентрации усилий на период. Пример: «Сокращение time-to-first-value».
- **Гипотеза** — предположение о том, как изменится метрика.
- **Инициатива** — конкретное действие.

**Анти-паттерн:** «Сделать новый онбординг» — инициатива, не фокус.

### 5 типов фокусов

| Тип | Примеры |
|-----|---------|
| **Рост** (Acquisition, Activation, Viral Loop) | Повышение конверсии активации |
| **Удержание** (Retention, Engagement) | Ускорение value discovery (aha-moment) |
| **Монетизация** (Conversion, ARPU, Pricing) | Улучшение paywall |
| **UX Improvement** | Упрощение поискового сценария |
| **Платформенные / технические** | Снижение ошибок на критическом шаге |

### Как выбрать 3–5 ключевых фокусов

1. Опираемся на цели продукта
2. Разбираем воронки и сегменты
3. Ищем точки потерь и узкие места
4. Проверяем ограничения ресурсов
5. Смотрим на влияние фокуса на метрики

## Блок 2. Продуктовые ставки

### Что такое ставка

**Ставка — крупная гипотеза, которая при успехе существенно меняет ключевую метрику.**

Ставка всегда: связана с фокусом, имеет подтверждённую боль, описывает механизм влияния, измерима.

### Примеры

- «Сократим time-to-value → повысим retention на 10 п.п.»
- «Введём guided onboarding → повысим активацию с 40% до 55%»
- «Снизим drop-off на оплате → конверсия +20%»

### Чек-лист ставки

| # | Критерий |
|---|----------|
| 1 | Внутри выбранного фокуса? |
| 2 | Есть конкретная боль? |
| 3 | Подтверждена данными? |
| 4 | Понятна причинно-следственная связь? |
| 5 | Есть измеримый целевой эффект? |
| 6 | Понимаем ограничения и ресурсы? |

## Блок 3. Проверка боли

### JTBD как инструмент

- Что человек пытается сделать?
- Что мешает достичь результата?
- Какой прогресс пытается получить?

Если продукт «не нанят» → незакрытая боль.

### CustDev: сигналы реальной боли

- **Частота ситуации** — боль регулярна
- **Эмоциональная реакция** — расстроен, злится
- **Высокая цена бездействия** — что будет, если не решить
- **Workaround** — уже обходит проблему костылями

### Behavioral data

Сигналы в данных: длительное время на шаге, высокий drop-off, повторные действия, попытки обойти ограничения.

### Подтверждение

**Количественное:** воронки, сегментация, retention curves, cohort analysis.
**Монетарное (самый сильный):** платит или готов платить → боль точно есть.

## Блок 4. Портфель инициатив

### Матрица Impact / Effort

| Impact | Effort | Решение |
|--------|--------|---------|
| Высокий | Низкий | **Делать сразу** |
| Высокий | Высокий | **Big bet** |
| Низкий | Низкий | **Быстрые проверки** |
| Низкий | Высокий | **Отказаться** |

### Балансировка

Хороший портфель: 1–2 big bets, 3–5 mid bets, 5–10 small bets.

### Анти-паттерны

| Проблема | Почему плохо |
|----------|-------------|
| Только мелкие правки | Нет прорывного роста |
| Только big bets | Высокий риск, долго нет результатов |
| Только UX-правки | Не решает фундаментальные проблемы |
| Только монетизация | Выжимает пользователя, убивает retention |

## Выходной артефакт

1. **Список фокусов** — 3–5 с привязкой к стримам и целям
2. **Продуктовые ставки** — с чек-листом по каждой
3. **Подтверждение боли** — данные и сигналы
4. **Портфель инициатив** — сбалансированный по Impact/Effort
5. **Матрица приоритизации** — визуализация
