## Блок 1. Обзор фреймворков роста

### Ключевое различие: линейная воронка vs петля роста

**Линейная воронка (AARRR, HEART):** требует постоянного наполнения «сверху» — внешних инвестиций в привлечение. Пользователи необратимо уходят на каждом этапе.

**Петля роста (Flywheel, Growth Loops):** замкнутый цикл, где результат одного цикла (привлечённый пользователь, созданный контент) становится причиной для привлечения новых пользователей в следующем цикле. Генерирует рост «изнутри».

### Выбор фреймворка по типу продукта

| Тип продукта | Рекомендуемый фреймворк |
|-------------|------------------------|
| **E-commerce** | AARRR |
| **SaaS** | Воронка пути + HEART |
| **Игры** | Growth Loop |
| **Социальные сети** | Growth Loop + HEART |
| **Медиа** | Growth Loop + HEART |

**Важно:** это не жёсткое правило. Выбор модели роста — индивидуальный рецепт для каждого продукта. Нужно взвесить все факторы и выбрать то, что работает. Или придумать своё. Главное — чтобы сходилась математика.

**Факторы выбора:** стадия продукта, бизнес-цели, рынок, тип продукта.

## Блок 2. AARRR (Pirate Metrics)

Линейная модель, фокус на привлечение и монетизацию пользовательской ценности. Применяется в: Авито, Яндексе, Amazon и др.

### Шесть этапов с каналами и метриками

**1. Awareness (Осведомлённость)** — люди узнают о вас

Каналы: SEO, SEM, Content, Affiliate, PR, Social networks, Mailing, ASO

Метрики: Visits, Impressions/Reach, CTR, CPC, CPM, Bounce rate, Engagement rate

**2. Acquisition (Привлечение)** — посетители идентифицированы

Каналы: Blog, White papers, Chat widgets, Newsletter subscription, Landing pages, Webinars, Retargeting, Quizzes, Exit popups, Tools

Метрики: Email subscriptions, Resource downloads, Chats, Cost per Lead, Trial signups

**3. Activation (Активация)** — первый отличный опыт

Каналы: User experience, Traditional sales, Tutorials, Customer support, Onboarding, Drip campaigns

Метрики: Freemiums, Core feature usage, Onboarding success rate, Hits/Signups, CAC

Ключевой момент: **Aha-момент** — точка, в которой пользователь осознаёт ценность продукта и решает продолжить использование.

**4. Retention (Удержание)** — пользователи возвращаются

Каналы: Email marketing, Customer lifetime marketing, Retargeting, Product marketing, Additional features, Push notifications

Метрики: Churn rate, App usage, Returning customers, DAU, MAU

**5. Revenue (Монетизация)** — поведение генерирует доход

Каналы: UX, Sales, Product, Checkout process

Метрики: CLV, Conversion rate, Upselling, Abandonment rate, Cross-sells, Average cart size, CLV/CAC ratio

**6. Referral (Реферальность)** — пользователи приводят новых

Каналы: Referral marketing, Core referral functionalities, Sharing mechanisms, App ratings, Testimonials, Viral campaigns, Inherent virality

Метрики: User invites, Social shares, Viral coefficient, Backlinks, NPS, Referral transactions / Total transactions

### Недостатки AARRR

- Требует постоянного наполнения верха воронки (дорого, ограниченная масштабируемость)
- Пользователи необратимо уходят на каждом этапе (Churn)
- Не учитывает петли обратной связи

## Блок 3. HEART (фреймворк Google)

Линейная модель, фокус на качество UX продукта. Применяется в: Google Maps, YouTube, Spotify, Slack, Duolingo и др.

### Структура: Goal → Signals → Metrics

Для каждого измерения HEART определяются:
- **Goal** — чего хотим достичь
- **Signals** — какие сигналы пользователей об этом говорят
- **Metrics** — как измерить количественно

### Пять измерений

**Happiness (Счастье):**
Цель: удобство и надёжность продукта для повседневного использования.
Сигналы: позитивная обратная связь, высокие рейтинги, мало жалоб на юзабилити.
Метрики: App store rating, In-app satisfaction survey, Customer Effort Score (CES).

**Engagement (Вовлечённость):**
Цель: частое использование для основных сценариев.
Сигналы: рост ежедневного/еженедельного использования, больше целевых действий.
Метрики: DAU, Average actions per user, Number of saved/favorite items.

**Adoption (Принятие):**
Цель: привлечение новых пользователей.
Сигналы: рост скачиваний, больше первых запусков, быстрый онбординг.
Метрики: Download rate, Time to Value (от первого запуска до первого успеха), Onboarding completion rate.

**Retention (Удержание):**
Цель: пользователи продолжают использовать продукт регулярно.
Сигналы: возвращающиеся пользователи, повторные действия.
Метрики: 30-day / 90-day Retention rate, MAU, Churn/Uninstall rate.

**Task Success (Успех задачи):**
Цель: быстро и точно решить задачу пользователя с минимальным трением.
Сигналы: быстрое выполнение, мало ошибок, минимум времени на поиск.
Метрики: Average time to complete task, Search success rate, Error rate.

## Блок 4. Flywheel / Маховик продукта

Циклическая модель (петля роста). Фокус на UX-продукте и социальной ценности. Применяется в: Zoom, Airtable, Dropbox и др.

### Цикл: Activate → Adopt → Adore → Advocate

| Этап | Сегмент пользователя | Стратегия | Метрика |
|------|----------------------|-----------|---------|
| **Activate** | Оценивающий (Evaluator) | Дать простой и быстрый способ испытать ценность продукта (Aha-момент). Убрать все барьеры к первому успеху. | Sign-up rate |
| **Adopt** | Новичок (Beginner) | Помочь сформировать привычку регулярного использования. Обучить новым функциям, дающим дополнительную ценность. | Retention rate |
| **Adore** | Постоянный пользователь (Regular) | Постоянно улучшать опыт, предвосхищать потребности, чтобы пользователь не просто использовал, а любил продукт. | NPS |
| **Advocate** | Чемпион (Champion) | Побуждать довольных пользователей рекомендовать продукт (сарафанное радио). Запускает новый цикл маховика. | Referrals invited |

### Пример: Авито Работа (профессия X, сегмент Y)

**Положительные петли:**
- Больше резюме → больше откликов
- Больше релевантных откликов и наймов → больше работодателей
- Больше работодателей, готовых платить → выручка Авито
- Больше вакансий / шире выбор → больше соискателей

**Отрицательные петли (контроль):**
- Меньше соискателей → больше мошенников и абьюзеров

Ключевое: маховик — это замкнутый цикл. Результат Advocate (рекомендации) запускает новый цикл Activate для новых пользователей.

## Блок 5. Growth Loops

### Определение

Growth Loop (цепочка роста) — замкнутый цикл, где результат одного цикла (привлечённый пользователь или созданный контент) становится причиной для привлечения новых пользователей в следующем цикле.

### Отличие от линейной воронки

- **Линейная воронка:** требует постоянных внешних инвестиций (рекламный бюджет)
- **Growth Loop:** генерирует новые входы (новых пользователей) из предыдущих выходов (действий текущих пользователей)

### Универсальный цикл роста

```
Product Grows → More & Higher Quality Resources (People & Capital) → Solve New Meaningful Problems → Product Grows
```

### Growth Loop Framework: проектирование петли

**Фаза 1: Observe (Наблюдение)**

1. Опиши реальный сценарий — что пользователи делают в жизни
2. Почему они это делают? Мотивации:
   - **To look good** — выглядеть хорошо в глазах других
   - **To feel good** — получать удовольствие
   - **To help others** — помогать другим
   - **To get** — получить что-то ценное
   - **To bond** — укрепить связи
   - **To convince** — убедить или повлиять

**Фаза 2: Design (Проектирование)**

3. Что мотивирует пользователя и как отразить это в продукте?
4. Какое действие мы ожидаем и как упростить/улучшить его?
5. Какой результат получит пользователь и как усилить его эффект?

**Фаза 3: Iterate (Итерация)**

6. Шаги для отслеживания — определить ключевые точки в петле
7. Метрики — как измерять каждый шаг

### Пример: медицинский контент

**Observe:** врачи часто делятся медицинской информацией в профессиональных группах.

**Why:** хотят узнавать новое, помогать коллегам, чувствовать себя профессионалами/лидерами.

**Design:**
- Врачи читают и пишут медицинский контент со своим мнением
- Хотят поделиться с коллегами
- Продукт помогает найти подтверждающую информацию и данные для исследований

**Результат:**
- Другие видят контент врача с фото и регалиями
- Другие хотят создать свой контент
- Оригинальный автор получает признание

**Метрики:**
- Сколько статей прочитано / отмечено интересными
- Сколько раз поделились
- Сколько людей пришло по ссылке
- Сколько регистраций с UTM-ссылок

## Блок 6. Growth Model Canvas

Стратегический шаблон, объединяющий все элементы модели роста в единую структуру.

### Компоненты Canvas

1. **Target Audience** — персона клиентского сегмента
2. **Value Proposition(s)** — почему эти клиенты будут покупать
3. **North Star Metric** — метрика, измеряющая добавленную ценность для клиентов
4. **WOW Moment** — момент, когда пользователь поражён ценностным предложением
5. **Product DNA** — клиенты нуждаются в продукте и «подсажены» на него

### Шесть этапов Canvas

| Этап | Суть | Ключевые метрики |
|------|------|------------------|
| **Awareness** | Люди узнают о вас | Visits, CTR, CPM |
| **Acquisition** | Посетители идентифицированы | Email subs, Cost per Lead, Trial signups |
| **Activation** | Первый отличный опыт | Feature usage, Onboarding rate, CAC |
| **Retention** | Пользователи возвращаются | Churn, DAU, MAU |
| **Revenue** | Поведение генерирует доход | CLV, Conversion, Cart size |
| **Referral** | Пользователи приводят новых | Viral coefficient, NPS, Referral rate |

## Выходной артефакт

При проектировании модели роста результат включает:

1. **Выбор фреймворка** — обоснование по типу продукта и стадии
2. **Воронка или петля** — визуализация этапов с метриками
3. **Каналы по этапам** — конкретные каналы привлечения/удержания/реферальности
4. **Growth Loop** — спроектированная петля роста (если применимо): сценарий, мотивация, действие, результат, метрики
5. **Growth Model Canvas** — заполненный шаблон с NSM, WOW Moment, Product DNA
6. **Контрольные метрики** — что измерять на каждом этапе
