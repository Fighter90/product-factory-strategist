# Коммуникационная стратегия: Вывод cvstart.org на европейский рынок

> Основание: продуктовая стратегия — вариант C, три волны [04_product_strategy]; trial-trap фон рынка [C022][C024][C026]; OSS-ядро [C004][C005]; локали [C007]. Коммуникация обслуживает выбранную стратегию и не меняет её.

## Аудитория и ситуация

**Ядро волны 1 — tech-соискатели DE/NL/SE, 25–40, EN-профессионалы** (те же сегменты, что в продуктовой стратегии). Момент решения — активный поиск: соискатель обновляет резюме, получает отказы или ноль откликов и ищет «как улучшить CV / пройти ATS / создать Lebenslauf». Где принимает решение:
- Google-запросы вида «Lebenslauf kostenlos / ohne Abo / Alternative zu …» (DE long-tail);
- треды Reddit — r/cscareerquestionsEU (~179k [C074]) и r/Germany_Jobs (54k), где обсуждают ATS, Lebenslauf-конвенции и конкретные CV-сервисы;
- онбординг-сервисы, которыми уже пользуется: XING-конструктор Lebenslauf [C021], trial-конструкторы CVMaker/LiveCareer [C022][C024][C026].

**Второй контур — OSS/self-host аудитория** (разработчики): решение принимает в GitHub при выборе self-host инструмента; сравнение с Reactive Resume (45k звёзд — потолок ниши) [C032]. Момент решения — «показывает trending / попал в Show HN / увидел ответ на Reddit».

**Волны 2–3 (PL, затем FR/ES)** — локально-язычные соискатели: решение принимают на локальном языке («lebenslauf erstellen», «lettre de motivation modèle», «plantilla CV»), потому что локальный язык обязателен: DE [C017], FR [C018], ES [C019]; в SE английский — норма IT [C020]. Их коммуникация стартует только в своей волне, с готовыми локальными форматами документов.

Контекст выбора у всех сегментов общий: рынок приучил, что «бесплатный конструктор резюме» — это €2–3 триал → €21–25 автопродление [C022][C024][C026], а биллинг глобальных игроков — в USD [C025][C027].

## Барьер понимания или выбора

**Главный барьер — недоверие.** Слово «бесплатно» на этом рынке обесценено: CVMaker — €1,99 триал → €21,99/мес автопродлением [C022], resume.io — €2,95/7 дней → €24,95/4 нед [C026], LiveCareer PL — 99 zł/4 нед [C024]. Обжёгшийся соискатель по умолчанию ищет подвох в любом «бесплатно» (где карта, где водяной знак, где автосписание). Поэтому сообщение «бесплатно, без автопродлений» работает только с доказательством-артефактом: открытый MIT-код и отсутствие платёжного контура как факт продукта [C005]. Важно: сама конверсия «free+честно» против trial-trap — гипотеза, ещё не проверенная [C051]; волна 1 спроектирована как её проверка.

Вторичные барьеры:
- **Привычка** (DE): бесплатный XING-конструктор уже привычен [C021] — ответ: «это не конструктор резюме, а весь цикл: скан вакансий → AI-скоринг → тюминг CV → трекер», чего у XING нет [C021];
- **Риск** (privacy-мышление tech-аудитории): «моё резюме и JD уйдут в чужое облако» — ответ: 100% локально, BYOK [C004].

## Ключевое сообщение

**«Найди, оцени и оформи отклик на работу в Европе — бесплатно, без автопродлений, всё локально на твоём компьютере».**

Опорные тезисы:
1. **Бесплатно и честно**: $0 forever (MIT), без триала и привязки карты — и без автопродлений в любой форме [C005].
2. **Локально**: 100% локально, данные не покидают компьютер, BYOK [C004].
3. **Сделано для Европы**: 19 локалей интерфейса [C007] и локальные форматы документов — табличный Lebenslauf + Anschreiben в DE [C017], lettre de motivation во FR [C018], CV на испанском в ES [C019].

Альтернативные формулировки для A/B:
- RU: «Поиск работы в Европе: ~129 джоб-бордов, AI-скоринг, CV-студия — бесплатно и локально, без автопродлений» [C004][C005].
- EN (GitHub/HN): «Your job search, free and fair: scan boards, score, tailor — $0 forever (MIT), 100% local» [C004][C005].
- DE (для DE-страниц): **«Lebenslauf erstellen — kostenlos, ohne Abo, lokal»**; вариант B: «Bewerbungen finden, bewerten und schreiben — kostenlos, ohne Abo, lokal auf deinem Rechner».
  A/B механика: EN/DE-варианты ставятся на заголовки DE-SEO-страниц и README, сравнение по конверсии визит → первый импорт CV (метрика из дерева 04).

## Роль каналов

Путь: **узнать** (Show HN, heise, LinkedIn) → **понять** (Reddit-ответы, DE-SEO) → **попробовать** (GitHub → локальный запуск / сайт) → **остаться** (трекер, OSS-комьюнити).

| Канал | Задача в пути | Формат | Метрика |
|---|---|---|---|
| GitHub | Попробовать + остаться (OSS-контур); главный артефакт доверия | README с демо-GIF, таблицей «что бесплатно» и лицензией MIT; публичный roadmap; релизы с changelog | GitHub Stars (референс ниши: 45k у Reactive Resume [C032]; цель волны 1 — 400–1000 [04]) |
| Show HN | Узнать + понять (первый пик OSS-аудитории) | Show HN: техническая история «100% local, BYOK, 19 локалей» [C004][C007], без маркетинговых слов; ответы в комментариях от автора | Переходы на cvstart.org / GitHub из треда (пик-трафик + retention 30 дней [04]) |
| Reddit (answer-first!) | Понять + попробовать (tech-соискатели в момент боли) | Ответы на вопросы про Lebenslauf, ATS, CV-сервисы в r/cscareerquestionsEU (~179k) [C074] и r/Germany_Jobs; ссылка — только как источник решения в ответе; прямой self-promo = бан | Клики на cvstart.org из ответов |
| DE-SEO контент | Понять (mass-market DE, long-tail) | 10–12 long-tail страниц: «kostenlos», «ohne Abo», «Alternative zu CVMaker/resume.io» + гайд по табличному Lebenslauf [C017]; заголовки — DE-версии ключевого сообщения | Органические клики по DE-запросам (Search Console) |
| PR / heise | Узнать (массовый DE-охват) | Питч статьи для heise.de (5,68 млн UU) [C035]: «OSS-альтернатива trial-trap-конструкторам резюме» — сюжет про честность и локальность данных | Реферальный трафик со статьи |
| LinkedIn | Узнать + остаться (пассивно, без закупки) | Посты основателя: прогресс OSS, разборы механики автопродлений конкурентов [C022][C026] как публичная позиция | Переходы на cvstart.org из постов |

## Соответствие обещаний продукту

| Обещание | Чем подтверждено в продукте | Риск перепродать |
|---|---|---|
| «Бесплатно — $0 forever» | OSS MIT, монетизации нет [C005] | «Навсегда» честно только для **OSS core**; hosted-версия появится в этапе 2 **за деньги** — обещать её бесплатной нельзя и замалчивать её планы нельзя (комьюнити накажет за «сюрприз-монетизацию»: контрметрика −10% звёзд [04]) |
| «Без автопродлений» | Платёжного контура нет вообще [C005] | При запуске hosted (этап 2) обещание должно остаться: тарифы без автосписаний (годовая с напоминанием или кредиты [04]); иначе главный тезис умирает |
| «100% локально, данные не покидают компьютер» | Локальная архитектура, BYOK [C004] | Hosted — это облако; слово «локально» нельзя переносить на hosted-страницы; страницы разделить: «OSS = локально», «hosted = EU-хостинг» |
| «Мультиязычно — 19 локалей» | 19 локалей интерфейса [C007] | 19 локалей интерфейса ≠ перевод документов на 19 языков; формулировку не сглаживать до «резюме на 19 языках» |
| «Локальные форматы: табличный Lebenslauf, lettre de motivation, CV español» | Требование волн 1–3 [C017][C018][C019]; реализация — шаблоны CV Studio [C004] | **Не запускать DE-коммуникацию до готовности табличного Lebenslauf + Anschreiben** — иначе обещание ложно на главном DE-запросе |
| «Помогает пройти ATS» | AI-скоринг 0–5, ATS-буллеты [C004]; ATS стандарт де-факто: ~98% Fortune 500 (исследование Jobscan, 2018) [C061] | **Обещать «гарантию прохождения ATS» НЕЛЬЗЯ** — обещаем прозрачность методологии и качество буллетов, не результат [04] |
| «Честная альтернатива trial-trap-сервисам» | Публичные цены конкурентов [C022][C024][C026] | Сравнивать только фактами цен с публичных страниц, без ярлыков («мошенники», «обман») — иначе PR- и юридический риск; в единой единице (€/мес при честном продлении [04]) |
