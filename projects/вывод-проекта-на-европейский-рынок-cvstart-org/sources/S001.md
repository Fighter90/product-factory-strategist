# The open-source job search command center
Scan ~135 job boards, score every posting 0–5 against your CV, generate tailored PDF resumes and track every application — from one local browser tab.
Your CV and applications never leave your computer.

Up and running in one command
curlnpxgit clone

curl -fsSL https://raw.githubusercontent.com/Fighter90/career-ops-ui/main/bin/setup.sh | bash
ⓘ On Windows, run these commands inside WSL (Ubuntu) — a macOS/Linux shell is required.

✓ dependencies installed
→ http://127.0.0.1:4317

cd career-ops/web-ui
npx career-ops-ui setup
ⓘ On Windows, run these commands inside WSL (Ubuntu) — a macOS/Linux shell is required.

git clone https://github.com/Fighter90/career-ops-ui.git web-ui
cd web-ui && bash bin/start.sh

The UI lives inside a career-ops project as web-ui/ — the start script installs dependencies and opens the dashboard.

## How it works
Four steps from an empty folder to a tracked, scored job pipeline.
- 
01
### Install
One command clones career-ops and the UI, installs dependencies and opens the dashboard at 127.0.0.1:4317 — nothing runs in the cloud.
- 
02
### Scan
Pull fresh postings from ~135 job boards — Greenhouse, Ashby, Lever, Workable, Workday and more — deduplicated into one list.
- 
03
### Evaluate
AI scores each posting 0.0–5.0 against your actual CV on a rubric of five dimensions plus a holistic global score, and writes a report you can audit line by line.
- 
04
### Apply & track
Generate a tailored PDF or DOCX resume and a cover letter, then track statuses, responses and follow-ups in one board.

### What the score tells you
- ≥ 4.5apply now
- 4.0 – 4.4apply, or start with a warm intro
- 3.5 – 3.9research the company first
- < 3.5skipRead the full guide

## Everything a serious job search needs
One local app instead of five subscriptions and ten browser tabs.
- 
### Scan ~135 job boards
Greenhouse, Ashby, Lever, Workable, SmartRecruiters, Workday, hh.ru and dozens more — direct API scanning at zero cost.
- 
### AI fit score 0–5
A rubric of five dimensions plus a holistic global score scored against your actual CV, not keyword bingo. Every score ships with a written report.
- 
### Auto-pipeline
Paste a job URL — it verifies the posting is live, evaluates it, writes the report and updates the tracker.
- 
### Application tracker
Every application on one board with clean statuses, notes and history — stored as plain markdown you own.
- 
### CV Studio (PDF + DOCX)
Tailor your CV to a pasted job description and export ATS-friendly PDF or DOCX in one click.
- 
### Cover letters
Grounded in your CV and profile. Reformulated, never fabricated — no invented achievements.
- 
### Deep research & interview prep
Company research briefs, interview prep guides and a mock-interview mode with feedback.
- 
### Follow-up cadence
A cadence board tells you exactly which application to nudge and when — no more forgotten threads.
- 
### Statistics & rejection patterns
Funnel analytics, target-role trends and rejection-pattern analysis — over your own data, locally.
- 
### 18 AI providers — or none
Anthropic, Gemini, OpenAI, Qwen, OpenRouter, GitHub Models — or a keyless copy-the-prompt mode that works with any assistant.
- 
### Private by design
Local markdown and YAML files, a server bound to 127.0.0.1, no cloud accounts, no telemetry, no auto-submit.
- 
### 19 languages, RTL included
The app, the full user guide and this site ship in 19 languages — including right-to-left Arabic.

## Frequently asked questions
Is it really free?
Yes. The software is MIT-licensed open source — no subscription, no trial, no locked tiers. If you enable live AI features you bring your own API key and pay your provider directly, or use the keyless copy-the-prompt mode and pay nothing at all.How is this different from Jobscan or Teal?
Those are paid cloud subscriptions that store your resume on their servers. career-ops-ui is free, open-source and runs on your machine: unlimited scans and match scores, a pipeline that groups postings by board with one-click undo, and your CV never leaves your computer.Where is my data stored?
In plain markdown and YAML files in a folder you own. The server binds to 127.0.0.1, so nothing is reachable from outside your machine, and there is no telemetry.Do I need an AI API key?
No. The keyless mode copies a ready-made prompt to your clipboard for any AI assistant you already use. Adding a key from any of the 18 supported providers unlocks one-click live runs.What do I need to install it?
Node.js ≥ 18 and git, on macOS, Linux or Windows (WSL). One curl command sets up everything else.Does it auto-submit applications?
No — by principle. It drafts, fills and prepares; you review and press send. Nothing is ever submitted on your behalf.Which job boards can it scan?
135 job-board sources: 130 international boards (Greenhouse, Ashby, Lever, Workable, SmartRecruiters, Workday, Recruitee, Teamtailor, remote-work aggregators and more) plus 5 Russian ones (hh.ru, Habr Career, GetMatch, GeekJob, Trudvsem). New boards are drop-in adapter files.Which languages does it support?
19: English, Spanish, French, Portuguese (BR), Korean, Japanese, Russian, Chinese (Simplified and Traditional), Polish, Ukrainian, Danish, Arabic (RTL), German, Italian, Turkish, Hindi, Tamil and Vietnamese — including the full user guide.Can I contribute?
Yes — issues, pull requests and translations are all welcome. Start with the contributing guide on GitHub.Is this affiliated with career-ops?
No. It is an unofficial UI built on top of the open-source career-ops pipeline — not affiliated with or endorsed by career-ops / santifer.
