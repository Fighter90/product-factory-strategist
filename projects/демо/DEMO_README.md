# Демо-проект «CVStart: коммерческая версия и глобальный GTM»

Полный 12-шаговый прогон агента «Стратег Фабрики продуктов» на живом open-source
продукте [cvstart.org](https://cvstart.org). Все данные — только открытые источники;
синтетические интервью помечены `origin=synthetic` и используются как метод, не как прогноз.

## Задача руководителя

> Вывести cvstart.org (open-source AI-конструктор резюме + поиск вакансий) на мировой
> рынок как коммерческий продукт. Выбрать модель коммерциализации и подготовить
> стратегию глобального запуска с планом проверки.

## Ключевые результаты

- **Решение D001:** «Коммерческая версия CVStart: hosted freemium SaaS, глобально».
  Основания — 6 утверждений [C019/C013/C014/C016/C005/C006]; пересмотр 2027-02-10.
- **Экономика:** ARPU $29 (взвешенный по тирам) → контрибуция $21,75 →
  LTV ≈ $271,88 → LTV/CAC ≈ 4,5 → брейк-евен ≈ 69 платящих.
- **Гейт:** `pfs check --strict` — 100/100, 0 ошибок.
- **План проверки:** 90 дней; продолжить ≥40 / изменить 20–40 / остановить <20 платящих.

## Как воспроизвести

```bash
git clone https://github.com/Fighter90/product-factory-strategist-agent.git
cd product-factory-strategist-agent && bash scripts/install.sh
pfs --project демо status            # 12/12 шагов, состояние восстанавливается
pfs --project демо check --strict    # гейт качества: 0 ошибок
pfs --project демо finish            # пересобрать пакет одним вызовом
```
