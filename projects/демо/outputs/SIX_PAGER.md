## FAQ-3. Стратегические инициативы. Кратко обоснуйте каждую.

### 03 · Варианты — CVStart (коммерческая версия + глобальный GTM)

Экономика — формулы на допущениях; рынок — [^3] [^4]; конкуренты — [^5] [^5]. Возражения — red team (субагент), без смягчения.

#### Вариант A. Оставить как есть — бесплатный локальный OSS без коммерческой версии

- Экономика: $0 выручки; затраты — время соло-разработчика + инфраструктура GitHub (~$0–20/мес).
- Возражения red team: (1) **ноль по оси задачи** — $0 ARR при цели «рост платящих»; домен, CI и 129 интеграций субсидируются из кармана бессрочно; (2) **MIT = чужая монетизация**: любой форкнёт код и завернёт в закрытый hosted SaaS «в один клик» (прецедент WordPress/WP Engine), уведя аудиторию и бренд; (3) **разложение актива**: 129 скраперов и 18 провайдеров — активы с сроком годности (борды меняют разметку, API ломаются), без выручки — стагнация за 12–24 месяца на рынке с CAGR 13% [^3].
- Скрытое допущение: что локальность/приватность — реальный драйвер выбора для массового пользователя; если большинство хочет «открыл с телефона → готово», локальный режим обслуживает единицы процентов рынка.
- Условие верности: если цель — портфолио и комьюнити, а не коммерция (противоречит интейк-брифу).

#### Вариант B. Hosted freemium SaaS — облачная версия, глобально (рекомендация)

- Экономика: тарифы Pro $12 / Unlimited $29 → ARPU средневзвешенный $18,80 (микс 60/40 долей платящих — допущение); переменные 25% → CM $14,10; LTV ≈ $176; freemium: CR free→paid 5,5% → CAC платящего ≈ $1 091, LTV/CAC платящего ≈ 0,16 — платный канал при такой конверсии не окупается, экономику держит органика (денежный CAC ≈ 0). Синтетическая бета-воронка: 53 платящих и $1,5 тыс MRR к 12-й неделе [^8]. Тарифы: Free (3 резюме/мес, watermarked PDF) / Pro $12 / Unlimited $29 (скан+AI).
- Глобально: EN-first (US/EU) → затем из 19 готовых локалей включать DE/ES/PT-BR/JA/ZH волнами — конкуренты сидят на EN+5 [^5]. Каналы запуска: Product Hunt, HN («open-source, локальный, BYOK — против $29/мес автопродлений»), SEO «open-source Jobscan alternative».
- Возражения red team: (1) **юридика PII и скрапинга переходит на разработчика**: hosted делает его контролёром персональных данных (GDPR, DPA, процедуры утечек), серверный скан бордов = скрапинг против ToS с риском исков (линия hiQ v. LinkedIn) и расходов на прокси; (2) **обвал единственного актива — доверия**: «100% локально, $0 forever» — публичное обещание на сайте; запуск подписки = та модель, от которой аудитория бежала; HN/PH отреагируют обвинениями в bait-and-switch, «$0 forever» вернётся скриншотами; (3) **деньги и рынок против**: freemium-конверсия 2–5%, продукт эпизодический (нашёл работу — отписался, churn естественно высокий), PH/HN дают спайк на дни, соло-разработчик не тянет круглосуточный аптайм + саппорт + PDF-рендер под нагрузкой.
- Скрытое допущение: что аудитория, пришедшая ради локального OSS, купит hosted-подписку; скорее наоборот — эти пользователи пришли избегать SaaS и облаков с PII; привлечение «обычных» соискателей — война на поле конкурентов с бюджетами.
- **Митигации, встроенные в вариант**: BYOK-free-тир (нулевые инференс-затраты на free), opt-in облако при локальном core (доверие сохраняется), честный прайсинг без автопродлений как позиционирование, пороги остановки из 06.
- Условие верности: BYOK-режим для free (пользователь приносит свой ключ — нулевые переменные затраты на free-тир), платные — на инфраструктурных ключах; beta-порог из 06.

#### Вариант C. B2B white-label — лицензирование карьерным центрам, вузам, outplacement

- Экономика (модельные вилки): лицензия $200–500/сайт/мес или $5–15 тыс/год институционально; цикл продаж 1–3 мес; 10 клиентов = $24–60 тыс ARR.
- Возражения red team: (1) **продажи не по размеру**: тендеры, RFP, security review, циклы 6–18 мес; $200–500/сайт/мес — слишком дёшево для тендера и слишком рискованно без SOC2/страхования; (2) **продукт не тот**: центрам нужны админ-панель, когорты, отчётность по трудоустройству, SSO/SAML, LMS-интеграции (Canvas/Moodle), WCAG/ADA, FERPA — разворот продукта на 180° силами одного человека; (3) **ниша занята** вертикальными вендорами (Handshake, Symplicity, VMock, Big Interview) с референсами; потолок — десятки клиентов × $500/мес при тяжёлом саппорт-хвосте.
- Скрытое допущение: что в сегменте есть неудовлетворённый спрос на white-label резюме-инструмент; BYOK («студент приводит свой ключ OpenAI») в enterprise-сценарии — дезайблити.
- Условие верности: если найдётся 1–2 якорных институциональных пилота с оплатой.

#### Вариант D. Open-core dual-license — enterprise self-host + ATS-интеграции

- Экономика (модельная вилка): enterprise-лицензия $2–5 тыс/год за self-host инстанс + платные интеграции (Greenhouse/Workday API); целевой сегмент — small recruiting agencies.
- Возражения red team: (1) **юридически не работает поверх MIT**: права уже розданы всем навсегда — «enterprise-лицензия» на код под MIT = продажа пустоты, любой соберёт своё; moat = 0; (2) **неверный покупатель ATS-интеграций**: Greenhouse/Workday — инструменты работодателей, а CVStart — кандидатский продукт; официальные API закрыты, партнёрские программы требуют юрлицо, страховку и security review; (3) **энтерпрайз не покупает у физлица**: SLA, SOC2/ISO, договоры от $10k+/год — закупка не подпишет контракт с инди без юрлица и аттестаций.
- Скрытое допущение: что энтерпрайз заплатит за то, что уже бесплатно под MIT, и что ATS-вендоры допустят стороннюю интеграцию.
- Условие верности: только после смены лицензии (CLA/переписывание) — долго и рискованно.

#### Вариант E. Закрыть коммерческую ветку — проект остаётся некоммерческим OSS

- Экономика: $0; экономия времени на коммерцию.
- Возражения red team: (1) **отказ от оси в момент максимального окна**: дифференциация «честная цена без автопродлений» сейчас сильнее всего — конкуренты на $8–40/мес ловят хейт за автопродления, AI-сегмент растёт на 13% CAGR [^3]; (2) **сжигание времени без плана Б**: тысячи часов при нулевом возврате; любой шок останавливает проект; (3) **«некоммерческий навсегда» — мина**: публичное обязательство заблокирует будущую монетизацию с бэклэшем (кейсы Audacity и подобных), а без CLA права на контрибьюции размазаны.
- Скрытое допущение: что сообщество поддержит проект — статистика OSS упрямее: контрибутируют <1% пользователей; «качественный OSS = самовоспроизводящийся» — самый часто опровергаемый миф опенсорса (эффект Heartbleed).
- Условие верности: если гипотеза C014 (честный прайсинг как дифференциатор) опровергается тестом.

ARPU средневзвешенный по тарифам: Pro 12,00 × 60,00% + Unlimited 29,00 × 40,00% = **18,80**.

| Формула | Расчёт | Результат |
|---|---|---|
| CM = ARPU × (1 − доля переменных) | 18,80 × (1 − 0,25) = 18,80 × 0,75 | **CM = 14,10** |
| Средняя жизнь платящего = 1 / churn | 1 / 0,08 | **12,50 мес** |
| CAC платящего = CAC / конверсия free → paid | 60,00 / 0,06 | **1090,91** |
| LTV = CM / churn | 14,10 / 0,08 | **LTV = 176,25** |
| LTV/CAC | 176,25 / 1090,91 | **0,16** (критерий ≥ 3) |
| Окупаемость CAC = CAC / CM | 1090,91 / 14,10 | **77,37 мес** |

**Вывод (умозаключение):** критерий LTV/CAC ≥ 3 не выполняется: фактический 0,16 при CAC платящего 1090,91 — для ≥ 3 нужен CAC платящего ≤ 58,75 при этом LTV (сценарии и сетка — листы «Сценарии» и «Чувствительность» unit_economics.xlsx).

### 04 · Продуктовая стратегия — CVStart: коммерческая версия и глобальный GTM

Основание: выбор руководителя — вариант B, hosted freemium SaaS глобально с митигациями [^9]; рынок и тренды [^3] [^7]; ограничения интейк (MIT core, соло, доверие).

#### Аудитория и её задача

**Ядро (EN-first):** соискатели tech/цифровых профессий 25–40 лет, глобально (US, EU, удалёнка), активно ищущие работу 1–6 месяцев. JTBD: «Когда я ищу работу, помогите мне найти релевантные вакансии из всех источников и быстро сделать резюме под каждую, которое пройдёт ATS, — без ручной рутины, без подписных ловушек и без загрузки личных данных в чужое облако» (дискавери: синтетика [^10] [^11]).

**Волна 2 (не-EN сегменты):** DE, ES, PT-BR, JA, ZH — 19 локалей уже существуют в продукте [^2], конкуренты покрывают EN+5 [^5]; синтетика (Маркус, Берлин) [^11] — интерфейс и локальные конвенции важнее цены.

#### Альтернативы пользователя

Платные SaaS: Jobscan $49,95/мес, Teal $29/30 дней, Rezi $29, Zety $23,70 (автопродление), resume.io ≈$39/мес эффективно [^5]; ручной ChatGPT (бесплатно, но без джоб-сканов и трекера); ничего (ручная рутина) [^7] [^7].

#### Выбранное направление: вариант B — hosted freemium SaaS с митигациями

1. **Три тира**: Free (BYOK-ключ пользователя: нулевые инференс-затраты, 3 резюме/мес) / Pro $12 (облачный AI, безлимит резюме) / Unlimited $29 (скан 129 бордов + авто-пайплайн + трекер+follow-up).
2. **Opt-in облако при локальном core**: MIT-версия остаётся навсегда; облако — выбор, не требование. Обещание локального режима не ломается [^1] [^9].
3. **Честный прайсинг как позиционирование**: без автопродлений, отмена в один клик, годовой тариф со скидкой — прямая противоположность паттерну конкурентов [^5] и подтверждение гипотезы.
4. **Волны локалей**: EN (US/EU) → DE/ES/PT-BR → JA/ZH — каждая волна после подтверждения конверсии предыдущей.
5. **Открытая методология скоринга**: страница Methodology уже существует [^1] — расширить публичным описанием ATS-критериев (98% F500 используют ATS [^6] — прозрачность как доверие).

#### Осознанные отказы

- **Не строить B2B white-label** (вариант C) — нет продаж-компетенции, чужой продукт [red team C].
- **Не переходить на dual-license** (D) — юридически не работает поверх MIT [red team D1].
- **Не обещать «гарантию прохождения ATS»** — обещаем прозрачность методологии, не результат.
- **Не отключать локальный режим** — ядро доверия [^1].

#### Экономика направления (формулы на допущениях)

- Юнит (платящий): ARPU средневзвешенный $18,80 — микс тарифов Pro $12 × 60% + Unlimited $29 × 40% (доли — допущение, не цена топ-тарифа); переменные 25% → **CM $14,10**; churn 8%/мес → **LTV ≈ $176,25**; freemium: CR free→paid 5,5% → **CAC платящего ≈ $1 090,91**, **LTV/CAC платящего ≈ 0,16** — платный канал при такой конверсии не окупается (сценарии — лист «Сценарии» unit_economics.xlsx).
- **Брейк-евен**: фиксированные ~$1,5 тыс/мес (хостинг+база поддержки) ≈ **69 платящих**.
- Синтетическая бета-воронка [^8]: к неделе 12 — **53 платящих, MRR $1 537** (иллюстрация метода, не прогноз).
- Чувствительность — Excel-книга unit_economics (приложения six-pager).

## FAQ-5. Высокоуровневый план реализации

### 06 · План проверки — CVStart hosted beta (90 дней)

#### Ожидаемое изменение

Запуск hosted-беты: нед. 12 — **50–60 платящих (модель: 53), MRR ≥ $1 500**, активация (первое резюме) ≥ 50% от регистраций [^8]. Гипотезы под проверку: готовность платить [^10], честный прайсинг как дифференциатор, opt-in облако не ломает доверие [^1].

#### С чем сравниваем

База — синтетическая модель воронки [^8] (методическая кривая) + публичные ориентиры freemium-конверсии 2–5% [red team B3]. Реальной истории нет — продукт новый; сравнение «модель vs факт» по неделям.

#### Срок наблюдения

**90 дней** (~13 недель) hosted-беты; еженедельный разбор воронки. Факт модели нед. 12 [^8]: 32 603 посетителей → 1 793 регистрации → 1 111 активаций → 53 платящих (MRR $1 537).

#### Нежелательные последствия (контрметрики)

- Отток OSS-комьюнити: падение звёзд/форков GitHub после анонса облака [red team B2].
- Жалобы на приватность/GDPR-запросы > 5 шт — сигнал ломки доверия [red team B1].
- Инференс-затраты free-тира > $200/мес — экономика free ломается.
- NPS беты < 30 при росте регистраций — «растём в мусор».

#### Критерии решения

- **Продолжить**: paid ≥ 40 к нед. 12, activation ≥ 50%, churn платящих ≤ 10%/мес → масштабирование каналов, включение волны локалей DE/ES/PT-BR; приоритет — Unlimited-тариф для не-EN волн.
- **Изменить**: paid 20–40 → пересобрать тир/цену ($19?), усилить онбординг активации; частота пушей вниз.
- **Остановить**: paid < 20 к нед. 12 при activation < 35% → коммерческая ветка закрывается, проект остаётся OSS (вариант E), ресурсы — в комьюнити.

Ожидаемое распределение вклада инициатив в общий результат (сумма 100%):

- __% — Инициатива 1;
- __% — Инициатива 2;
- __% — Инициатива 3.

Порядок тактик: высокий → средний → базовый приоритет. Тайминг — к сезонам рынка. Параллельные треки: комьюнити/партнёрства — вне основной линии.

**Решение D001** — Коммерческая версия CVStart: hosted freemium SaaS, глобально. Промежуточный пересмотр 2027-02-10; триггер: paid < 20 к нед. 12 при activation < 35% -> закрыть коммерческую ветку (вариант E); падение звёзд GitHub > 30% после анонса облака -> пересобрать коммуникацию opt-in.

## FAQ-6. Метрики успеха. KPI в двух плоскостях

KPI в двух направлениях: **1) Бизнес** — деньги и база (выручка/MRR, платящие, конверсия в оплату, доля тарифов, фактический LTV/CAC); **2) Продукт** — активация, время до первой ценности, число действий до результата, churn, CSAT/NPS. У каждого KPI: база → цель к сроку → порог действия. Контр-метрики — по одной на удар red team.
