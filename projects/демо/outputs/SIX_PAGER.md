### Инициативы выбранного направления (драйверы)

Сформулируйте 3–4 инициативы по схеме: «**Первый драйвер** — …», «**Второй драйвер** — …», далее «Ключевые направления» (буллеты) и пошаговый расчёт эффекта. Данные — разделы «Варианты», «Выбор руководителя» и «Инициативы» пакета. Закройте выводом-умозаключением.

Юнит-экономика — расчёт пошагово:

Допущения: ПРИМЕР (демо): ARPU средневзвешенный — Pro $12 × 60% + Unlimited $29 × 40% = $18,80 (доли платящих — допущение микса, не цена топ-тарифа); freemium: CR free→paid 5,5% (как conv_order в growth) → CAC платящего = 60/0,055 ≈ $1 090,91; LTV/CAC платящего ≈ 0,16 — иллюстрация метода PRO-51: платный канал при такой конверсии не окупается
ARPU средневзвешенный по тарифам: Pro 12,00 × 60,00% + Unlimited 29,00 × 40,00% = **18,80**.

| Формула | Расчёт | Результат |
|---|---|---|
| CM = ARPU × (1 − доля переменных) | 18,80 × (1 − 0,25) = 18,80 × 0,75 | **CM = 14,10** |
| Средняя жизнь платящего = 1 / churn | 1 / 0,08 | **12,50 мес** |
| CAC платящего = CAC / конверсия free → paid | 60,00 / 0,06 | **1090,91** |
| LTV = CM / churn | 14,10 / 0,08 | **LTV = 176,25** |
| LTV/CAC | 176,25 / 1090,91 | **0,16** (критерий ≥ 3) |
| Окупаемость CAC = CAC / CM | 1090,91 / 14,10 | **77,37 мес** |

**Вывод (умозаключение):** критерий LTV/CAC ≥ 3 не выполняется: фактический 0,16 при CAC платящего 1090,91 — для ≥ 3 нужен CAC платящего ≤ 58,75 при этом LTV (сценарии и сетка — листы «Сценарии» и «Чувствительность» unit_economics.xlsx).
