# Услуга «Антиспам для звонков» будет бесплатной для абонентов t2

 Владимир Ромашов 

 15:57, 11 декабря 2024 

Компания t2 с завтрашнего дня сделает доступной для своих абонентов всех регионов и на всех устройствах услугу «Антиспам для звонков». Эта услуга обеспечивает защиту клиентов от нежелательных звонков. Пользователь будет получать сведения о статусе звонящего на экране своего смартфона, если входящий номер есть в базе t2. Эта информация поможет принять решение, отвечать на звонок или нет. Для абонентов мобильного оператора t2 услуга предоставляется бесплатно. «Антиспам для звонков» дополняет услугу «Антиспам», которая обеспечивает защиту пользователя от спам-рассылок посредством SMS.
