# Бриф: Защита от спам- и мошеннических звонков

> Демонстрационный проект. Задача сформулирована от лица руководителя продукта условного оператора связи.
> Внутренних данных МегаФона и других компаний нет: только открытые источники и модельные (синтетические) данные,
> помеченные как таковые [C057].

| Поле | Значение |
|---|---|
| Исходный запрос (дословно) | Платная защита от спам- и мошеннических звонков у оператора теряет подписчиков: после антифрод-закона и бесплатных функций у конкурентов люди не понимают, зачем платить. Что делать с продуктом и что говорить абонентам? |
| Уточнённый вопрос | Какую модель сервиса защиты от нежелательных звонков выбрать на 2027 год (оставить платную подписку, переупаковать ценность, перевести базовую защиту в бесплатную с платными расширениями, закрыть отдельный продукт) и какое сообщение поможет абоненту понять ценность? |
| Решение по результату | Модель сервиса и ключевое сообщение на 2027 год [C058] |
| Цель и критерий успеха | Рекомендация, которой комитет может доверять: варианты с возражениями, экономика с диапазонами, план проверки |
| Получатель и формат | Продуктовый комитет; документ + 10-минутная защита [C058] |
| Ограничения | Только открытые данные; требования 41-ФЗ и регулирования связи; бренд оператора — не обещать «100 % защиты» |
| Доступные данные | Открытые источники (регуляторы, ЦБ, сайты операторов и сервисов, исследования); модельный набор для демонстрации расчёта когорт (синтетика) |
| Разрешённые источники | Любые открытые; запрещены закрытые данные компаний и персональные данные |
| Вне рамок | Технические детали антифрод-платформ; юридическое заключение |
| Дедлайн | Демо: одна рабочая сессия |

## Допущения intake
- [C057] задача модельная; [C058] решение о модели сервиса на 2027 год, получатель — продуктовый комитет.
