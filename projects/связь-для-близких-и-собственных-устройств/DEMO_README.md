# DEMO_README — как читать пакет за 60 секунд

Проект: **«Связь для близких и собственных устройств»** (бриф заказчика, учебный рынок) · полный 12-шаговый прогон агента «Стратег Фабрики продуктов» · решение D001 утверждено руководителем · `pfs check --strict`: 0 ошибок.

Публичный контекст: бриф заказчика опубликован на странице кейса; в прогон он вошёл материалом руководителя — источник [S001], полный текст `sources/raw/brief.md`.

## Главный документ — для жюри и руководителя

| Файл | Что это |
|---|---|
| **`outputs/BRIEF_RESPONSE.md`** | **Ответ на бриф: один документ из пяти частей** (как требует бриф): 1) первые клиенты, проблема, предложение, ожидаемый результат; 2) разбор проблемы с восстановлением случая и сопоставлением с альтернативой; 3) предложение, путь обеих ролей, одна операция до конца, привлечение и прогноз подключений; 4) польза (−3 п.п. ограничений), прибыль (500 ₽/мес, граница 12 000 мес, окупаемость), пробный запуск; 5) выбор из 5 вариантов, план по кварталам, прогноз по всем 5 строкам, ресурсы, риски, конкретная просьба. Расчёты рядом с решениями. |

## Ключевые числа (все из брифа [S001], расчёт воспроизводим)

- Цель планового года: **валовая прибыль ≥285 млн ₽** («без изменений» 279; разрыв 6 млн = **12 000 доп. оплаченных месяцев × 500 ₽** [C003]).
- Целевой сценар: 5 500 номеров × 3 мес − 1,5 млн расходов = **+6,75 млн → 285,8 млн**; неблагоприятный: 280,5; «ноль»: 277,5 [C021].
- Клиентский результат: доля ограничений из-за исчерпания **12% → 9% (−3 п.п.)** [C013].
- Активные группы: 8 000 = 2/3 от 12 000 подключённых (сейчас 62,5% [C008]).
- Ориентир 3-го года: ≥25% доступной базы (100 тыс. домохозяйств [C004]).

## Помощь человека — 3 обязательные паузы

1. **Intake:** бриф передан руководителем, задача подтверждена («подгони пример стратегии под этот бриф»).
2. **Choice:** руководитель утвердил вариант B «Предупреждение до перебоя».
3. **Decision:** руководитель утвердил D001 (пилот 600 групп, пересмотр конец Q2).

Между паузами агент вёл шаги сам; состояние — в `state.json`/`log.jsonl` (продолжение после перерыва: `pfs status`).
