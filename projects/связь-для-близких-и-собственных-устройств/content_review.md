# Контент-экспертиза пакета «Связь для близких» (content_review)

> Проверка формулировок: тон, канцелярит, жаргон, нерасшифрованные сокращения, бренды заказчика, обещания без подтверждения. Дата: 2026-11-19. Охват: 00–07, BRIEF_RESPONSE, DEMO_README.

## Вердикт

Пакет читается руководителем без словаря: решения названы прямо, расчёты стоят рядом с решениями, жаргон расшифрован при первом употреблении (MAU, KPI, NPS, CSAT, JTBD, CAC, LTV, AOV, ITT, MDE — проверено линтером six-pager). Брендов заказчика и сторонних операторов нет — аналоги описаны как способы клиента («банковский автоплатёж», «семейный чат») [S001].

## Стилистические решения (оставлены сознательно)

- «Предупреждение до перебоя» — имя услуги: короткое, отражает момент ценности; не «уведомления о балансе» (канцелярит) и не «умный контроль семьи» (обещание шире продукта).
- «Учебные числа» — повторяется в бриф-обращениях: честная рамка для жюри, все числа сверяемы с [S001].
- Синтетические интервью подписаны «гипотезы, не доказательство» в каждом упоминании [S002,S003,C019,C020] — правило п. 3 AGENTS.md.
- Диапазоны вместо точечных прогнозов там, где решающего числа нет (частоты причин [C011]) — требование брифа.

## Не найдено (проверено grep'ом по пакету)

- Институциональные термины и бренды: `мегафон|megafon|магистрат|ВШЭ|НИУ|авито|avito` — 0 в tracked-файлах.
- Нерасшифрованные сокращения при первом упоминании — 0 (линтер six-pager).
- Обещания без подтверждения в таблицах 04/05 — 0 (гейт «обещание → подтверждение»).

## Остаточные ограничения (заявлены честно)

1. Источник S001 зарегистрирован из файла за пределами проекта (копия в `sources/raw/`) — пометка в карточке источника сохранена намеренно: материал явно передан руководителем.
2. Квоты/мощность пилота: MDE считается до старта (pre-registration) — на момент подачи выборка 600 групп взята из примера брифа [C027,C025].
3. CSAT/NPS-база отсутствует (нет продукта) — в six-pager помечено честным пробелом.
