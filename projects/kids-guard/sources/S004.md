# S004. Google Family Link (официальная справка)

- Ссылка/файл: https://support.google.com/families/answer/7101025?hl=ru
- Тип: text; происхождение: public
- Получено: 2026-11-05T21:12:57+03:00

---

Family Link — бесплатный родительский контроль Google: создание детского аккаунта, лимиты экранного времени, одобрение приложений, геолокация устройства, блокировка устройства, расписание. Ограничения: детский контроль настраивается только на устройствах Android 6+ (время — 7+); на iPhone/iPad ребёнка родительский контроль через Family Link настроить нельзя; на iOS работает только родительское приложение. Для системных приложений ограничения времени невозможны. Ребёнок видит установленные ограничения; обход технически возможен и повышает риски (вирусы, потеря данных).
