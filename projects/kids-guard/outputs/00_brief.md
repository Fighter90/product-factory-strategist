# Бриф: Семейная защита детей (родительский контроль)

> Составлен агентом по ответам руководителя (ворота intake). Демо-задача на открытых данных.

| Поле | Значение |
|---|---|
| Исходный запрос (дословно) | Семейная подписка «родительский контроль» растёт медленно: родители отключают сервис после бесплатного периода, встроенные бесплатные функции ОС перебивают ценность. Куда развивать продукт и что сказать родителям, чтобы он приносил и пользу, и деньги? |
| Уточнённый вопрос | Какую ценность добавить и какую упаковку/сообщение выбрать, чтобы подписка «родительский контроль» для детей 7–12 росла по ARPU без роста оттока (цена ≤199 ₽/мес)? |
| Решение по результату | Направление развития продукта + ключевое сообщение родителям на 2027 год |
| Цель и критерий успеха | Рост ARPU подписки без роста оттока; решение, обоснованное открытыми данными и экономикой |
| Получатель и формат | Продуктовый комитет; six-pager с Excel-расчётами |
| Ограничения | Цена ≤199 ₽/мес; только открытые данные; без обещаний «100 % защиты» (регуляторная чувствительность) |
| Приоритетный сегмент | Родители детей 7–12 лет (первый смартфон) |
| Доступные данные | Открытые источники (исследования, сайты конкурентов, ОС); модельные когорты для методики (помечены синтетикой) |
| Разрешённые источники | Любые открытые; запрещены закрытые данные операторов и ПДн |
| Вне рамок | Техническая реализация фильтров; юридическое заключение по 436-ФЗ/152-ФЗ |
| Дедлайн | Одна рабочая сессия |

## Допущения intake
- C001: задача модельная, решение — о развитии существующей подписки (не о выводе на рынок с нуля) [S001]
- C002: приоритетный сегмент — родители детей 7–12; ценовое окно ≤199 ₽/мес; критерий — ARPU без оттока [S001]
