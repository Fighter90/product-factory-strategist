# Connection for loved ones: family group vs own router

Manager request (verbatim):

> A mobile carrier: some customers help loved ones with connectivity (family groups with a shared data package — the organizer learns about an outage only when the relative asks for help), others manage several own numbers (a router — they rarely notice the money or data ran out). Who to help first, what to change, and why should the operator invest? One-year plan, a measurable target for the end of year three. Two decisions: end of Q1 — fund a pilot?; end of Q2 — expand, adjust, or keep observing? If information is insufficient, show exactly what is missing and what can be done before it arrives.
