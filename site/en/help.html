How to work with the agent

Write in plain language, as to a colleague. The agent drives steps 1–12 on its own, asks at most three questions at a time and explains what it is missing. Below: control, commands and answers to frequent questions.

Key points

The whole gist in one minute

Evidence, not eloquence

Every number and conclusion: a type (fact, hypothesis, forecast, assumption, inference), an A–D grade and a source. The chain S### → C### → D### is traceable from a link to a decision.

Twelve steps, three decisions are yours

The agent drives: brief → sources → research → situation → options → choice → strategies → validation → review → decision → monitoring.

Honest options

At least three substantively distinct ones, including “keep as is” and “shut it down”. A dedicated red-team subagent attacks each.

State lives in files

projects/<slug>/ stores everything. A new chat, another tool, a break — work resumes where it stopped, with no repeats.

Formula Excel

Four workbooks: unit economics, growth, cohorts, market. The input sheet holds the parameters — change them and the formulas recalculate.

Transparency and cost

An action log, grounds behind conclusions, cost in tokens and money: pfs cost, pfs next, pfs check --strict.

Communication

Three kinds of messages, never more than three questions

A task

“Why is in-app retention dropping”, “who should we sell the new service to” — plain language, no commands.

Answers to its questions

Pick an option or reply freely — the answer is stored and grounds the next steps.

Control phrases

“stop”, “clarify: …”, “build the six-pager” — process control (table below).

A good first request names the decision to make: “Help me decide whether to launch antispam as a paid subscription; here is the brief and six months of data.” A weak one (“make me a strategy”) also works — the agent clarifies the decision, audience and constraints before spending your tokens.

Control

Control phrases

“stop”

pause: state saved, the agent stays quiet until a new command

“clarify: …”

adjust the task; only the affected part is redone, sources are not duplicated

“redo section X”

targeted rework of a single document section

“what should I decide now”

pfs next: current step, overdue decisions, stale grounds, open questions

“what is due”

pfs decision due: decisions and commitments whose review date has arrived

“what will a new source affect”

pfs impact: which conclusions, document lines and decisions go stale

“build the six-pager”

pfs calc all + pfs export --six-pager: the FAQ-1…6 report and four Excel workbooks

“recalculate Excel”

pfs calc all — workbooks rebuilt from the current calcs.json

“build the report” / “build the deck”

pfs export → REPORT.md; pfs export --deck → an HTML deck

“make it a doc”

pfs docx file.md — Markdown to Word, dependency-free

“check the project”

pfs check --strict — numbers, links, options

“how much did it cost”

pfs cost — tokens and money per model

Quick start

Five minutes to your first task

You need Python 3.9+ and one of the supported tools. No packages to install — the standard library only. Secrets (MCP keys) go to .env — it is git-ignored and not required for the basic loop.

  1. 1 · Clone the repository
    git clone https://github.com/Fighter90/product-factory-strategist.git
  2. 2 · Install pfs
    cd product-factory-strategist && ./scripts/install.sh
  3. 3 · Check your setup
    pfs doctor
  4. 4 · Open the folder in your tool
    opencode
First project

What happens after pfs new

$ pfs new "Name" "the request verbatim"
Created projects/<slug> · active project · next: intake
step 1 · intakeup to three questions

The agent classifies the scenario, asks the intake question block — up to three questions with options and a recommendation — writes the brief to outputs/00_brief.md and stops for your approval. That is the first of three human pauses. Switch projects with pfs use, list them with pfs list, inspect state with pfs status.

The cycle

Twelve steps in four phases

Each step has mandatory knowledge cards, a question block, quality gates and an artifact. Progress shows in one line: “Step 3/12 · research · sources · next: situation”.

  1. 1Brief
  2. 2Sources

  4. 4Segments

  1. 5Situation
  2. 6Options and red team

  3. 10Quality review

Deliver · 11–12

  1. 11Decision
  2. 12Monitoring
Steps 1–4 · research

registering sources with dedup and domain checks, a plan built from questions that could change the decision, claims with type and quote, personas and JTBD. Synthetic data yields hypotheses only.

Steps 5–7 · define

what is known and from where, what is not; options with economics and red-team objections; the human choice becomes the ground for the strategies.

Steps 8–10 · develop

product and communication strategies with a “promise → product proof” table, a validation plan with five mandatory sections, an independent rubric review.

Steps 11–12 · deliver

a decision with grounds, a metric and a review date; deadline monitoring and refreshing conclusions as new data arrives.

FAQ

Frequently asked

How do I resume after a break?+

All state lives in projects/<slug>/: state.json, claims.jsonl, decisions.jsonl, log.jsonl, sources/, outputs/. A new chat in the repository folder resumes from the same step; in a tool without hooks, write “read AGENTS.md and run pfs status”. Completed steps are never repeated.

How do I move a project between tools?+

A project is a plain folder: copy projects/<slug>/ (or git push/pull) and open it in another tool. Secrets in .env are not carried over automatically — move them by hand and never commit them.

What data does the agent use?+

Only open sources and the materials you hand over yourself. Allowed domains are set per project and checked before each request; instructions found inside source texts are never executed — they are flagged as data.

What does pfs check verify?+

A fact without a source — error; a fact resting only on synthetic data — error; a link to a missing or retracted C###/S###/D### — error with a replacement hint; a naked number in a document — warning; fewer than three options or no “keep as is” — error; a missing mandatory validation section — error.

What about frequent errors?+

“A fact without a source is not allowed” — by design: add a source or record a hypothesis. “The domain is not in the allowed list” — edit allowed_sources in project.json. “Extracted 0 characters” — the page renders via JavaScript: save the text by hand with --text-file.

What do C###, S### and D### mean?+

S### — a source with a quote and a hash, C### — a claim with a type and an A–D grade, D### — a decision with grounds and a review date. The committee’s six-page report is the six-pager; the option attack is the red team.
